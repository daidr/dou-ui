# 无障碍

图表可以用键盘浏览，读屏会读出数据的概要和每个位置的值，也可以把图表换成一张数据表。

## 数据表

`v-model:table` 为 `true` 时，图表的位置改为显示一张数据表，适合想直接看数字或复制数据的用户，也方便读屏用户逐格浏览。打开数据表的开关由页面提供。

<DocDemo src="chart/table" />

- 每个横轴位置一行，每个系列一列。数值按对应坐标轴的 `format` 写出，和提示框一致；隐藏的系列不列出。
- 坐标轴标题末尾括号里的单位，比如“销售额（万元）”里的“（万元）”，会加到这一列的列头上。
- 饼图每一块一行，写出值和占比；散点图每个点一行。
- 表格在图表的高度内滚动，表头固定。数据很多时只显示前 1000 行，并在下方注明总行数。
- 在表格里按 `Esc` 关闭数据表，回到图表。

## 键盘

图表可以用 `Tab` 聚焦，聚焦后：

- 方向键在各个位置之间移动，提示框跟着移动：右和下是下一个，左和上是上一个。
- `Home`、`End` 跳到第一个和最后一个位置，`Esc` 收起提示框，`Enter` 触发 `select`。
- 提示框按单个点显示且有几个系列时，沿横轴的一对方向键移动位置（横向图是上下），另一对切换系列，热力图是切换行。
- 有 `DouChartZoom` 时，`+`、`-` 键缩放，`0` 键复位；移到显示范围以外时，图表跟着平移。

## 读屏

图表的名称是自动生成的概要，`aria-label` 可以替换它。概要包括：

- x 轴的范围，横向图读作“纵轴”。
- 每个系列的名称、数据点个数、最小值和最大值，数值按坐标轴的 `format` 读出。
- 可以用方向键查看的提示；有 `DouChartZoom` 时还提示缩放的按键。

其他读屏行为：

- 有提示框时，图表是可以聚焦的分组（`role="group"`），用方向键移动时读出当前位置的各个值；关闭提示框后是一张图片（`role="img"`）。
- 图例是一组按钮，`aria-pressed` 表示系列是否显示，并提示可以按 `Alt` + `Enter` 只显示这一项。
- 数据表是真正的表格，每行的第一格是横轴值（`scope="row"`）。表格的标题是图表的 `aria-label`，没有时按系列名称生成，比如“销售额、毛利率的数据”。
- 区间条的两个手柄是滑块（`role="slider"`），方向键移动，`Page Up` / `Page Down` 一次移动十步。
- 用键盘缩放后，读出当前显示的范围。
