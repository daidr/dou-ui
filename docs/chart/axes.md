# 坐标轴

`DouChartAxis` 用于设置坐标轴的范围、刻度和标题。不写时，图表按数据自动显示横轴和纵轴。

## 基础用法

`for` 指定设置哪条轴：`x` 是 x 轴，`y` 是数值轴，`y2` 是第二条数值轴。

<DocDemo src="chart/axis" />

- `min`、`max` 固定坐标轴的范围。不设置时取数据的范围，数值轴还会向外取到整齐的刻度值。
- `format` 格式化刻度文字。数值轴上收到数字，时间轴上收到 `Date`，类目轴上收到类目的文字。不设置时，数值按当前语言格式化，较大的数写成“12万”这样的短格式。
- `ticks` 设置大致的刻度数量，也可以是具体的刻度值数组。刻度文字放不下时会自动减少刻度。
- `title` 设置坐标轴的标题。
- `grid` 控制网格线，默认只有 `y` 有（只有 `y2` 时是 `y2`）。
- `hidden` 隐藏坐标轴，但保留它的范围。

## 横轴的类型

横轴的类型由 `x` 字段的值决定：

| 值                                                               | 横轴                     |
| ---------------------------------------------------------------- | ------------------------ |
| 数字                                                             | 数值轴                   |
| `Date`，或 `'2026-10-31'`、`'2026-10-31 09:30'` 这样的日期字符串 | 时间轴                   |
| 其他字符串                                                       | 类目轴，按出现的顺序排列 |

- 不带时区的日期字符串按本地时间读取。
- 时间轴按跨度选择分钟、小时、天、周、月或年作为刻度。刻度文字只写变化的部分，跨天、跨月、跨年的位置写出完整的日期。
- 数值轴上 10000 以内的整数（比如年份 2019）不加千分位，整数数据之间不会出现小数刻度。

`type` 可以指定类型，比如 `<DouChartAxis for="x" type="category" />` 把数字年份当作类目。毫秒时间戳是数字，默认当作数值轴，需要写 `type="time"` 才按日期显示；开发环境下检测到像时间戳的横轴时，会在控制台提示。

## 第二条数值轴

系列默认对应 `y`，写上 `axis="y2"` 对应第二条数值轴，适合在一个图表里显示两种单位。

<DocDemo src="chart/dual-axis" />

- 竖向图里 `y` 在左侧、`y2` 在右侧；横向图里 `y` 在底部、`y2` 在顶部。
- 两条数值轴同时出现时，`y2` 的刻度和 `y` 对齐，只画一套网格线。
- 两条轴的范围都包含 0 时，两条轴的 0 也落在同一位置，柱子从同一条基线画起。
- 只写了 `y2` 时，系列默认对应 `y2`。

## 对数刻度

`type="log"` 使用对数刻度，适合跨越几个数量级的数据。对数轴上的柱子从轴的起点开始画，小于等于 0 的值不画，开发环境下会提示。

## 反向

`reverse` 让坐标轴反过来：数值轴从上往下增大，适合第 1 名放在最上面的排名数据；x 轴从右往左排列，横向图里从下往上排列。

<DocDemo src="chart/axis-reverse" />

## 类目排序

类目 x 轴默认按数据里出现的顺序排列。`sort="desc"` 按每个类目的合计值（显示中的系列之和）从大到小排列，`sort="asc"` 从小到大，也可以传入一个比较两个类目名称的函数。数据本身不需要提前排序。

<DocDemo src="chart/bar-sorted" />

## 对齐多个图表

上下排列的几个图表，给数值轴设置相同的 `labelWidth`，绘图区的左边就能对齐。示例见[缩放与框选 · 联动](./zoom#联动)。

## API

### Axis Props

| 名称         | 说明                                                                    | 类型                                                  | 默认值                      |
| ------------ | ----------------------------------------------------------------------- | ----------------------------------------------------- | --------------------------- |
| `for`        | 哪条轴                                                                  | `'x' \| 'y' \| 'y2'`                                  | —                           |
| `type`       | 刻度类型                                                                | `'linear' \| 'log' \| 'time' \| 'category'`           | x 轴按数据判断，数值轴线性  |
| `min`        | 起点                                                                    | `number \| string \| Date`                            | 数据的最小值                |
| `max`        | 终点                                                                    | `number \| string \| Date`                            | 数据的最大值                |
| `zero`       | 数值轴包含 0                                                            | `boolean`                                             | 有面积图、柱状图时为 `true` |
| `percent`    | 这条数值轴上的堆叠按占比画，叠满 100%，见[百分比堆叠](./bar#百分比堆叠) | `boolean`                                             | `false`                     |
| `nice`       | 两端取到整齐的刻度值                                                    | `boolean`                                             | 数值轴 `true`，x 轴 `false` |
| `ticks`      | 大约的刻度数量，或具体的刻度值                                          | `number \| (number \| string \| Date)[]`              | 按尺寸计算                  |
| `format`     | 格式化刻度文字                                                          | `(value: number \| Date \| string) => string`         | —                           |
| `grid`       | 显示网格线                                                              | `boolean`                                             | `y` 为 `true`               |
| `title`      | 标题                                                                    | `string`                                              | —                           |
| `hidden`     | 隐藏坐标轴，保留它的范围                                                | `boolean`                                             | `false`                     |
| `labelWidth` | 竖排刻度文字占的宽度（px）                                              | `number`                                              | 按文字测量                  |
| `reverse`    | 反向                                                                    | `boolean`                                             | `false`                     |
| `sort`       | 类目 x 轴的顺序：按合计值升序、降序，或比较类目名称的函数               | `'asc' \| 'desc' \| (a: string, b: string) => number` | 数据中的顺序                |
