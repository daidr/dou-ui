# 图表

`@dou-ui/chart` 用来画折线图、面积图、柱状图、散点图、饼图等统计图表。图表由一个外壳 `DouChart` 和写在里面的系列、坐标轴组成，每个部分都是一个组件，按需组合。

系列画在 canvas 上，数据量大时也能流畅绘制；坐标轴的刻度文字是普通的页面文字，跟随主题的字体和颜色。

几个完整页面的写法见区块中的[经营看板](../blocks/business)、[实时监控](../blocks/monitoring)和[门店对比](../blocks/compare)。

## 安装

图表是单独的包，需要和 `dou-ui` 一起使用：

```sh
bun add dou-ui @dou-ui/chart
```

引入样式，再注册组件：

```ts
import 'dou-ui/style.css'
import '@dou-ui/chart/style.css'
import { DouChart, DouChartAxis, DouChartBar, DouChartLine } from '@dou-ui/chart'

app.use(DouChart).use(DouChartAxis).use(DouChartLine).use(DouChartBar)
```

用到哪种系列就注册哪个组件：`DouChartLine`、`DouChartArea`、`DouChartBar`、`DouChartScatter`、`DouChartPie`。

## 基础用法

`data` 是一组行数据，`x` 指定横轴取哪个字段。系列组件用 `y` 指定纵轴的字段，`name` 是系列的名称。不写坐标轴时，图表自动显示底部的横轴和左侧的纵轴。

<DocDemo src="chart/basic" />

只有一个系列时用中性色。图表的宽度跟随容器，`height` 设置高度，默认 320px。

## 多个系列

多个系列按书写顺序依次使用图表色板里的颜色，图表下方自动显示图例；`:legend="false"` 可以关闭，只有一个系列时也可以用 `legend` 打开。`color` 可以指定任意 CSS 颜色，有明确含义时（比如错误数）用 `tone` 取语气色。

<DocDemo src="chart/multiple" />

`smooth` 把折线画成平滑的曲线。曲线经过每个数据点，并且不会在两点之间冲出比它们更高或更低的位置，峰值仍然落在真实的数据上。点太密时曲线和折线看不出区别，会直接画成折线。

折线的数据点之间有足够空间时会显示圆点，面积图默认不显示。`dots` 可以设为 `true` 或 `false` 固定显示或隐藏。`dots` 针对全部数据点；[迷你图](/components/sparkline)的 `markers` 是只标出首、尾、最高、最低几个点，两者含义不同。

## 阶梯线

`step` 把折线画成阶梯：值保持不变，到下一个点才变化，适合库存、价格、状态这类只在某些时刻改变的数据。`step` 或 `step="after"` 在下一个点处变化，`"before"` 在当前点处就变成下一个值，`"middle"` 在两点中间变化。阶梯线不受 `smooth` 影响，面积图也可以设置。

<DocDemo src="chart/step" />

## 横轴

横轴的类型由 `x` 字段的值决定：

| 值                                                               | 横轴                     |
| ---------------------------------------------------------------- | ------------------------ |
| 数字                                                             | 数值轴                   |
| `Date`，或 `'2026-10-31'`、`'2026-10-31 09:30'` 这样的日期字符串 | 时间轴                   |
| 其他字符串                                                       | 类目轴，按出现的顺序排列 |

不带时区的日期字符串按本地时间读取。时间轴会根据跨度选择刻度：分钟、小时、天、周、月或年，刻度文字只写变化的部分，跨天、跨月、跨年的位置写出完整的日期。

数值轴上 10000 以内的整数（比如年份 2019）不加千分位，并且整数数据之间不会出现小数刻度。也可以用 `<DouChartAxis for="x" type="category" />` 指定类型，比如把数字年份当作类目。

毫秒时间戳是数字，默认会当作数值轴，需要写 `type="time"` 才按日期显示；开发环境下检测到看起来像时间戳的横轴时会在控制台提示。

## 面积图与堆叠

`DouChartArea` 在折线下方填充浅色。面积图从 0 开始，所以纵轴一定包含 0。

<DocDemo src="chart/area" />

`stack` 相同的面积图依次叠在前一个上面，`stack` 为 `true` 时属于同一组。正数向上叠，负数向下叠。堆叠的系列需要使用同一份数据。

### 区间

`y0` 指定面积的下边界，面积图就画成从 `y0` 到 `y` 的一条带，比如每天的最低和最高气温、预测值的范围。这时面积不再从 0 开始，纵轴也不必包含 0；上下两条边线都会画出，`:line-width="0"` 只保留填充。提示框显示两端的值。`y0` 不能和 `stack` 一起使用。

<DocDemo src="chart/area-band" />

## 柱状图

`DouChartBar` 从 0 画到每个值。多个柱状系列在同一个位置并排显示。

<DocDemo src="chart/bar" />

柱子的宽度按每个位置的空间计算，空间很大时也不会超过 56px。`radius` 是柱子末端的圆角，默认 2px。

### 堆叠

和面积图一样，`stack` 相同的柱子叠在一起，`stack` 为 `true` 时属于同一组。只有最外面一段有圆角，各段之间留出 1px 的间隔。不同的 `stack` 名称会形成并排的几组堆叠。

<DocDemo src="chart/bar-stacked" />

### 百分比堆叠

数值轴设置 `percent` 后，这条轴上的每组堆叠都按各部分的占比画，每个位置都叠满 100%，适合比较构成的变化。刻度文字默认显示百分比，提示框同时显示原始的值和占比。面积图的堆叠也一样。

<DocDemo src="chart/bar-percent" />

### 负值

负数向下画，图表在 0 的位置画一条基准线。

`color` 也可以是一个函数，按每一行给柱子单独上色，返回 CSS 颜色或语气色名称（`danger`、`neutral` 等）；返回 `undefined` 的柱子用系列的颜色，图例和系列颜色一致。下面亏损的月份用 `danger`。散点图的 `color` 也可以这样写。

<DocDemo src="chart/bar-negative" />

### 横向

`horizontal` 把 x 轴放到左侧、数值放到底部，适合类目名称较长或者需要从上往下比较的情况。坐标轴和系列的含义不变，只是画的位置变了：`for="x"` 仍然是类目轴，`for="y"` 是底部的数值轴，`axis="y2"` 的系列对应顶部的第二条数值轴。从竖向改成横向只需要加上 `horizontal`。

左侧的类目名称最多占图表宽度的 40%，更长的名称末尾显示省略号，鼠标悬停时显示全文。

<DocDemo src="chart/bar-horizontal" />

横轴是数值或时间时也可以画柱状图，比如每天一根柱子。柱子的宽度按相邻两个值的最小间隔计算，横轴两端会各留出半根柱子的空间。柱子太密、每根不到 1.5px 时，同一像素列的柱子会合并成一根从最低值到最高值的柱子，看起来一样，绘制量只和图表宽度有关。

## 散点图

`DouChartScatter` 在每个数据点画一个圆点。圆点略微透明，重叠的地方颜色更深。系列可以用 `data` 带上自己的数据，图表的 `x` 对每个系列的数据都有效。

<DocDemo src="chart/scatter" />

`radius` 是圆点的半径，默认 3.5px。数据点超过 2000 个时，所有圆点会先合成一张图再一次画出，10 万个点重绘约 50ms；这时重叠的地方不再加深。

### 气泡图

`size` 指定每个点的大小，画成气泡：气泡的面积和值成正比，`radius` 是最大气泡的半径，默认 24px。大气泡先画，小气泡不会被盖住。

<DocDemo src="chart/bubble" />

## 饼图

`DouChartPie` 画一个饼图，`value` 是每一块的值，`label` 是每一块的名称，不写时使用图表的 `x`。各块按数据的顺序从 12 点钟方向顺时针排列，小于等于 0 的值不画。饼图没有坐标轴，下方的图例列出每一块。

<DocDemo src="chart/pie" />

每一块默认依次使用色板里的彩色，跳过第 1 个中性灰。`color` 可以给每一块指定颜色：字段名或函数，返回任意 CSS 颜色，或者 `danger` 这样的语气色名称；返回 `neutral` 时使用色板的中性灰，适合“其他”。色板只有 7 种彩色，块数更多时颜色会重复，建议把较小的几块合并成“其他”，开发环境下会在控制台提示。

`inner-radius` 是中间空洞占半径的比例，设置后画成环形图。默认插槽的内容显示在空洞中间，可以放合计或说明。

<DocDemo src="chart/donut" />

一个图表里只画一个饼图，饼图和其他系列不能放在同一个图表里。读屏会读出每一块的名称、值和占比，`name` 会读在最前面。

## 组合图

不同的系列可以放在同一个图表里，比如柱状图配合折线图，再用第二条数值轴显示另一种单位。

<DocDemo src="chart/combo" />

## 数据标签

`labels` 在图上直接写出每个值，按对应数值轴的 `format` 格式化；也可以传一个函数，参数是一个对象 `{ value, share, low, name, row, index }`：`value` 是值，`name` 是系列名称，百分比堆叠时 `share` 是占比，区间面积图的 `low` 是下沿的值；返回 `null` 或 `undefined` 的不写。会和别的标签重叠、或者超出绘图区的标签不显示，所以数据很密时只会显示一部分。设置了标签的数值轴会在两端多留出一些空间，最高的标签也能放下。

柱状图的标签默认写在柱子末端外面，`label-position="inside"` 写在柱子里面，放不下的不写。堆叠的柱子默认写在里面，文字颜色根据柱子的颜色选择深色或浅色。百分比堆叠的标签写占比，数值轴没有设置 `format` 时保留一位小数（比如 `33.3%`），刻度仍然是整数百分比。

<DocDemo src="chart/labels" />

折线和面积图的标签写在每个点的上方，点之间的空间不够时整条线都不写。`label-position="end"` 只在线的最后一个点旁边写一个标签，用系列的颜色。几条线的末端靠得很近时，标签会上下错开，每条线都保留自己的标签。下面用它直接写出系列名称，代替图例。

<DocDemo src="chart/labels-end" />

饼图的 `labels` 默认在外面写每一块的名称和占比，用一条线连到对应的块，饼图相应缩小留出空间；`label-position="inside"` 在每一块里面写占比，太小的块不写。函数的参数是一个对象 `{ value, share, name, row, index }`，`name` 是这一块的名称。外面的标签太多、一侧放不下时，较小的块不写。图表较窄时，太长的名称末尾省略，占比始终完整显示，鼠标移上去可以看到完整的文字；如果留出标签的位置后饼图太小，标签改为写在块里面。

<DocDemo src="chart/pie-labels" />

图表刚出现时，标签在系列画完之后才显示。导出的 SVG 和 PNG 里也包含标签。

## 坐标轴

`DouChartAxis` 用 `for` 指定设置的是哪条轴：`x` 是 x 轴，`y` 是数值轴，`y2` 是第二条数值轴。竖向图里 x 轴在底部，`y` 在左侧，`y2` 在右侧；横向图里 x 轴在左侧，`y` 在底部，`y2` 在顶部。

<DocDemo src="chart/dual-axis" />

系列默认对应 `y`，`axis="y2"` 对应第二条数值轴。只写了 `y2` 时，系列默认对应 `y2`。两条数值轴同时出现时，`y2` 的刻度会和 `y` 对齐，只画一套网格线；有负值、且两条轴的范围都包含 0 时，两条轴的 0 也会落在同一位置，柱子从同一条基线画起。

- `min`、`max` 固定坐标轴的范围；不设置时取数据的范围，纵轴还会向外取到整齐的刻度值。
- `format` 格式化刻度文字，收到的值在数值轴上是数字，时间轴上是 `Date`，类目轴上是类目的文字。不设置时，数值按当前语言格式化，较大的数会写成“12万”这样的短格式。
- `ticks` 是大致的刻度数量，也可以是具体的刻度值数组。刻度文字放不下时会自动减少刻度。
- `type="log"` 用对数刻度，适合跨越几个数量级的数据。对数轴上的柱子从轴的起点开始画，小于等于 0 的值不画，开发环境下会提示。
- `grid` 控制网格线，默认只有 `y` 有（只有 `y2` 时是 `y2`）；`title` 是坐标轴的标题；`hidden` 保留坐标轴的范围但不显示。

## 标注

`DouChartMarker` 在图表上标出参考线、区间和点，可以写多个。`x` 和 `y` 的写法决定画出什么：

| 写法                     | 画出                   |
| ------------------------ | ---------------------- |
| 只有 `y`                 | 一条横线，例如目标值   |
| 只有 `x`                 | 一条竖线，例如上线日期 |
| `x` 或 `y` 是 `[起, 止]` | 一段区间               |
| `x` 和 `y` 都是单个值    | 一个点                 |

横向图里方向随坐标轴一起转过来。`x` 的写法和横轴的数据一致：类目轴上是类目名，时间轴上是 `Date` 或日期字符串。

### 参考线

`y` 超出数据的范围时，数值轴会延伸到它，目标值总能显示出来。线默认是虚线，和数据区分开，`:dashed="false"` 画成实线。文字放在同色的浅底上，压在数据上也能看清；几个标注的文字靠得太近时会自动错开。

### 区间

区间画在系列下面，参考线和点画在系列上面。

### 点

`label` 是显示的文字，`tone` 是颜色，默认是中性色。`y` 对应 `y2` 时用 `axis="y2"`。缩放后移出绘图区的标注不显示，区间只画在绘图区里的部分。

## 自定义系列

`defineChartSeries` 用来定义自己的系列组件。它和内置系列一样放在 `DouChart` 里，共用坐标轴、堆叠、图例和配色，只需要说明两件事：坐标轴怎样包含它的数据（`zero`、`band`、`inset`），以及怎样画出来。

<DocDemo src="chart/custom" />

```ts
defineChartSeries({
  type: 'lollipop', // 组件名为 DouChartLollipop，图例里的类名为 is-lollipop
  zero: true, // 数值轴包含 0
  stackable: false, // 是否支持 stack
  band: false, // 是否像柱子一样在每个位置并排分配空间
  inset: (series) => 0, // 每个点周围需要留出的像素，比如气泡的半径
  tooltip: 'axis', // 提示框按位置（'axis'）还是按单个点（'item'）显示
  hit: undefined, // 按单个点显示时，找出指针下的点，默认找 12px 内最近的点
  prepare: undefined, // 数据不再变化、浏览器空闲时提前做的准备，返回值放在 series.prepared
  props: { radius: { type: Number, default: 5 } }, // 自己的属性
  draw(painter, series, view) {},
})
```

`draw` 收到三个参数：

- `painter`：canvas 2D 上下文的一部分方法，只通过它绘制。
- `series`：读取好的数据。`series.x.values` 是横轴的值（类目轴上是类目的序号），`series.top` 是要画的值（堆叠时是这一段的顶端），`series.base` 是堆叠时这一段的底端，`series.rows` 是原始的行数据，`series.props` 是组件的属性，`series.color` 是计算好的颜色；`color` 写成函数时，`series.colors` 是按行计算好的各点颜色，没有单独颜色的位置是 `undefined`。
- `view`：`point(x, value)` 返回这个值画在哪里，`[left, top]`，竖向和横向都一样，自定义系列一般只用它；`x`、`y` 是两个比例尺，`map` 把值换算成沿轴的像素；`horizontal` 表示横向；`band` 是每个位置的宽度（像素）；`plot` 是绘图区域。

内置的折线、面积、柱状和散点系列也通过同一个接口实现。

数据很多时，`hit` 逐个比较所有点会变慢，可以在 `prepare` 里提前建好索引。数据不再变化 300 毫秒后，图表会在浏览器空闲时调用 `prepare`，返回值放在 `series.prepared` 里；数据每秒更新很多次时（实时数据）不会调用。`prepare` 运行之前 `series.prepared` 是 `undefined`，所以 `hit` 和 `draw` 要能在没有它的情况下照常工作：

```ts
defineChartSeries({
  type: 'dots',
  tooltip: 'item',
  // 按 x 取整分桶：每个整数位置有哪些点
  prepare(series) {
    const buckets = new Map<number, number[]>()
    series.x.values.forEach((x, i) => {
      const key = Math.round(x)
      buckets.set(key, [...(buckets.get(key) ?? []), i])
    })
    return buckets
  },
  hit(series, view, px, py) {
    const buckets = series.prepared as Map<number, number[]> | undefined
    const x = Math.round(view.x.invert(px))
    // 还没有索引时逐个查找
    const candidates = buckets
      ? [x - 1, x, x + 1].flatMap((key) => buckets.get(key) ?? [])
      : series.x.values.map((_, i) => i)
    let best = null
    for (const i of candidates) {
      const [left, top] = view.point(series.x.values[i], series.top[i])
      const d = Math.hypot(left - px, top - py)
      if (d <= 12 && (!best || d < best.d)) best = { index: i, radius: 4, d }
    }
    return best
  },
  draw(painter, series, view) {
    /* … */
  },
})
```

## 提示框

鼠标移到图表上会显示提示框。折线、面积和柱状图显示指针所在位置的全部系列，并用一条竖线（柱状图是一条浅色的带）标出这个位置；散点图和饼图显示指针下的那一个点或那一块。手机上轻点显示，提示框放在这个位置的旁边，不挡住正在看的数据，点图表以外的地方收起。

写上 `DouChartTooltip` 可以调整它：`trigger` 改为按位置（`'axis'`）或按单个点（`'item'`）显示，`:crosshair="false"` 不画竖线，`disabled` 关闭提示框。默认插槽替换提示框的内容，参数里的 `title` 是这个位置（或系列）的名称，`items` 是每个系列的名称、按坐标轴格式化后的文字、原始的值、颜色和所在的行。

<DocDemo src="chart/tooltip" />

点击柱子、数据点或饼图的一块时触发 `select` 事件，用键盘移动到某个位置后按 Enter 也会触发。参数和提示框显示的内容相同：`x` 是这个位置原本的值（类目文字、时间轴上的 `Date` 或数字，饼图是这一块的名称），`items` 是这里的各个值和它们所在的行，可以用来进入明细。

有多个系列时，指针所在的系列会突出显示，其余的变淡，提示框里其他系列的文字也变浅：指针靠近某条折线（8px 以内）、在某根柱子上，或在某块面积里面时，突出这个系列；散点图突出指针下的点所在的系列。

散点图的提示框标题默认是系列名称，`label` 可以改用每个点自己的名称，比如气泡图里的城市；`size-name` 是气泡大小这一项显示的名称。

## 图例

点击图例可以隐藏或显示对应的系列，坐标轴随之按剩下的系列重新计算。最后一个显示的系列不能隐藏，鼠标移上去也不再变成可点的样子。鼠标移到图例上，或用键盘聚焦到图例时，对应的系列保持原样，其余的变淡。

按住 Alt（Mac 上是 ⌥）点击图例只显示这一个系列，再点一次恢复显示全部；手机上长按图例效果相同；键盘聚焦到图例时按 Alt+Enter。在手机上，图例的每一项都有足够的点按区域，多行图例的行距也相应加大。

系列的 `v-model:hidden` 绑定它是否隐藏，可以用来设置初始状态或在图表外面控制。饼图的 `v-model:hidden` 是隐藏的各块的名称组成的数组，按 `label` 的文字匹配，所以各块的名称应当不同。饼图隐藏了一些块之后，占比只按显示的块计算，提示框和读屏会注明隐藏了几项。

<DocDemo src="chart/legend" />

## 缩放与平移

放一个 `DouChartZoom`，图表就能放大查看局部：按住 Ctrl（Mac 上是 ⌘）滚动滚轮，或在触控板上双指捏合缩放；放大后拖动图表平移，左右滑动触控板也能平移；双击复位。手机上双指捏合缩放，单指左右拖动平移，上下滑动仍然滚动页面。

`v-model:x` 是显示的范围，值是数据本身（时间轴上是 `Date`，类目轴上是类目名），`null` 表示全部。`DouChartRange` 在图表下方画出全部数据的缩略图，拖动两端的手柄或中间的区域来调整范围。

<DocDemo src="chart/zoom" />

滚轮默认用来滚动页面，只有按住 Ctrl 时才缩放，这样页面滚过图表时不会被打断。图表占满整个页面时，可以设置 `wheel`，直接用滚轮缩放。

### 联动

几个图表的 `v-model:x` 绑定同一个值，缩放和平移就会一起变化。上下排列的图表给数值轴设置相同的 `label-width`，绘图区的左边就能对齐，同一天落在同一条竖线上。

<DocDemo src="chart/zoom-linked" />

`axis="xy"` 时数值轴也可以缩放，`v-model:y` 是数值的范围（有两个数值轴时是 `y` 轴的范围，`y2` 按同样的比例跟随）。数值范围精确到显示跨度的千分之一，显示给用户时仍可以按需要格式化。

## 框选

放一个 `DouChartBrush`，在图表上拖动就能选出一段范围，选区外的点和柱子会变淡（`dim` 设为 `false` 可以关闭）。松开时触发 `select`，参数是 `ChartBrushEvent`：选中的范围和落在其中的数据行。`axis` 设为 `x`（默认）、`y` 或 `xy`，分别是按横轴、按数值或框出一块区域。

选区会一直显示，按 Esc 或点击选区外面清除，清除时也会触发 `select`，这时没有 `x`、`y`，`rows` 为空。`v-model:x` 和 `v-model:y` 是选中的范围。

`DouChartBrush` 的 `select` 和图表本身的 `select` 不同：后者是点击柱子或数据点，参数是 `ChartSelectEvent`。

<DocDemo src="chart/brush" />

手机上按住不动片刻再拖动是框选，直接滑动仍是滚动页面。和 `DouChartZoom` 一起使用时，拖动是平移，按住 Shift 拖动是框选。用键盘时，聚焦图表后按住 Shift 再按方向键，从当前位置开始按横轴选择；框出一块区域（`axis="xy"`）只能用指针。

## 键盘与动画

图表可以用 Tab 聚焦。聚焦后用左右方向键在各个位置之间移动（横向图用上下方向键），提示框跟着移动，读屏会读出这个位置的各个值；散点图用上下方向键（横向图用左右方向键）切换系列。Home 和 End 跳到第一个和最后一个位置，Esc 收起提示框。有 `DouChartZoom` 时，加号和减号键缩放，0 键复位；放大后用方向键移到显示范围以外，图表会跟着平移。

图表第一次出现在屏幕上时，柱子和面积从基线长出来，折线从左到右画出，饼图沿顺时针展开；数据变化时各个值移动到新的位置。开启减弱动效时，或数据点超过 2000 个时，图表直接显示最终的样子。

## 缺失的数据

值为 `null`、`undefined` 或不是数字时，折线在这里断开。只有一个孤立的点时会画出它的圆点，避免这个点看不见。`connect-nulls` 会跳过缺失的值把线连起来。

## 大量数据

下面的图表有 100 万个点，可以缩放和拖动平移。

<DocDemo src="chart/large" />

一个像素宽的位置最多只能显示出最先、最低、最高和最后四个点，所以图表在每个像素列只画这四个点，画出来和逐点绘制完全一样，绘制量只和图表宽度有关。数据会读成连续的数字数组并缓存，之后的重绘不再读取原始的数据。

数据不再变化后，图表会在浏览器空闲时为折线建立分段的最低点和最高点，缩放和平移时整段跳过同一像素列里的点；散点图会建立网格索引，悬停时只查找指针附近的点。图表滚出屏幕后不再绘制，回到屏幕上时再画。

### 按列给数据

`data` 也可以按列给：一个对象，每个字段是一列，各列一样长。数据本来就是按列来的（例如接口返回的数组、二进制格式）时，不必先拼成一行一行的对象。列是 `Float64Array` 等类型化数组时，图表直接复制整列，不再逐个读取，100 万个点的数据也不占用逐行对象的内存。

```js
const data = shallowRef({
  time: new Float64Array([/* … */]),
  value: new Float64Array([/* … */]),
})
```

`x`、`y` 是字段名时直接读取那一列；是函数时，函数拿到的行是由各列拼成的对象。提示框、点击和框选给出的行也是这样拼成的对象，同一行每次都是同一个对象。

### 性能

下面是 bench 在一台普通笔记本的 Chromium 里测出的结果（每帧的工作时间，宽 1200 像素）。不同设备上的数字会不一样，手机通常要慢几倍。

| 场景                              | 时间         |
| --------------------------------- | ------------ |
| 100 万个点，按列给数据，首次绘制  | 约 45ms      |
| 100 万个点，按行给数据，首次绘制  | 约 70ms      |
| 100 万个点，缩放 / 平移每帧       | 约 4ms / 2ms |
| 100 万个点，悬停（折线 / 散点）   | 约 1ms       |
| 保留 1 万个点的实时数据，每次更新 | 约 2ms       |

使用大量数据时：

- 把数据放在 `shallowRef` 里，或用 `markRaw` 标记，避免 Vue 为每一行创建响应式代理。
- 更新时替换整个数组（或整个列对象），不要原地修改：缓存按数据本身区分，原地修改的数据不会重新读取。
- `x`、`y` 用字段名而不是函数。模板里写的箭头函数每次渲染都是新的，无法命中缓存。

### 实时数据

实时数据也是每次换成新数组：在上一个数组的末尾加上新的行，需要时从开头去掉旧的行。图表会认出新数组是接着上一个数组的，只读取新加的行，其余的数值直接沿用。下面的图表每 100 毫秒加一个读数，保留最近的 1 万个。

<DocDemo src="chart/live" />

沿用的前提是已有的行对象没有被改过，所以要修改某一行时，请换成一个新的对象。只沿用按字段名读取的列：`x`、`y` 是函数时，函数会拿到行的序号，行移动后序号就变了，所以每次都会全部重新读取。按列给的数据每次都会全部重新读取，实时数据请按行给。

## 没有数据

所有系列都没有数值时，图表不画坐标轴，只在中间显示“没有数据”。`empty` 插槽可以替换这部分内容。

## 加载中

`loading` 为 `true` 时，图表变淡，中间显示加载图标；这时没有数据也不显示“没有数据”。数据到了再把 `loading` 设回 `false`，已有的图表会过渡到新数据。

<DocDemo src="chart/loading" />

## 导出

通过 ref 调用 `exportSVG()` 得到 SVG 文本，`exportPNG()` 得到 PNG 图片的 `Blob`。导出的是图表当前的样子：隐藏的系列、缩放的范围和当前主题的颜色都和页面上一致，刻度文字、标题、图例和标注的文字都在里面；提示框、十字线和框选这些跟随指针的内容不导出。

<DocDemo src="chart/export" />

SVG 和画布用同一套绘制代码，两者画出的图形一致。导出的图四周默认留出 16px，用 `padding` 修改；`background: false` 不画背景色；`exportPNG({ pixelRatio })` 设置每个 CSS 像素对应几个像素，默认是 `2`。PNG 由 SVG 转成，文字使用系统里的字体：页面用网络字体时，导出的文字可能和页面上略有不同。

浏览器对画布的尺寸有限制（每边 16384 像素；总像素数在 iPhone 和 iPad 上约 1677 万，其他设备上是 16384 × 16384），图片很大时 `exportPNG()` 会自动降低 `pixelRatio`，降到 1 仍然放不下时会抛出 `RangeError`，不会生成一张模糊的图。图表一般不会这么大；遇到时可以减小 `padding`，或者改用 `exportSVG()`。

## 服务端渲染

在服务端渲染时，图表画成一张 SVG 放在页面里，刻度文字、图例和标注都在其中，脚本加载之前就能看到图表。SVG 的颜色用的是主题的 CSS 变量，跟随亮暗主题。

服务端不知道图表的宽度，所以按 `ssr-width`（默认 `640`）画出，再等比缩放到图表的区域里；`height` 是 CSS 长度时按 `320` 计算。浏览器接管页面后，图表按实际宽度画在画布上，然后去掉这张 SVG，不再播放入场动画。环形图中间插槽的内容在浏览器接管之后显示。

## 主题

图表的颜色都来自主题：系列颜色是 `--dou-color-chart-1` 到 `--dou-color-chart-8`，第 1 个是中性色，其余是低饱和的色相，并且明度错开，常见的色觉障碍下也能区分。切换暗色主题时图表会自动重绘。

| `axis`      | 缩放哪个方向：横轴、数值，或两者                    | `'x' \| 'y' \| 'xy'`       | `'x'`   |
| `wheel`     | 直接用滚轮缩放，不用按住 Ctrl                       | `boolean`                  | `false` |
| `disabled`  | 关闭缩放，显示全部                                  | `boolean`                  | `false` |
| `v-model:x` | 显示的横轴范围，`null` 表示全部                     | `[from, to] \| null`       | `null`  |
| `v-model:y` | 显示的数值范围（`axis` 含 `y` 时），`null` 表示全部 | `[number, number] \| null` | `null`  |

`from`、`to` 是数据本身：数值轴上是数字，时间轴上是 `Date`，类目轴上是类目名（两端都包含在内）。

### 读屏

图表的名称是自动生成的概要：x 轴的范围（横向图读作“纵轴”），以及每个系列的名称、数据点个数、最小值和最大值，最后提示可以用方向键查看。数值按对应坐标轴的 `format` 读出，和刻度文字一致。可以用 `aria-label` 替换。

有提示框时，图表是可以聚焦的分组（`role="group"`），用方向键移动时读出当前位置的各个值；关闭提示框后是一张图片（`role="img"`）。图例是一组按钮，`aria-pressed` 表示系列是否显示，每个按钮还会读出“按 Alt+Enter 只显示这一项”的提示。

有 `DouChartZoom` 时，概要里还会提示加号、减号和 0 键；用键盘缩放后读出当前显示的范围。区间条的两个手柄是滑块（`role="slider"`），用方向键移动，Page Up / Page Down 一次移动十步，读出的值是这一端的横轴值。按住 Shift 再按方向键可以按横轴框选。
