# 提示框与图例

鼠标移到图表上时显示提示框，点击图例可以隐藏或显示系列。

## 提示框

写上 `DouChartTooltip` 可以调整提示框。默认插槽替换提示框的内容。

<DocDemo src="chart/tooltip" />

- 折线、面积和柱状图显示指针所在位置的全部系列，并用一条竖线（柱状图是一条浅色的带）标出这个位置。
- 散点图和饼图只显示指针下的那一个点或那一块。
- `trigger` 改为按位置（`'axis'`）或按单个点（`'item'`）显示。
- `:crosshair="false"` 不画竖线，`disabled` 关闭提示框。
- 手机上轻点显示提示框，提示框放在这个位置的旁边，点图表以外的地方收起。

插槽参数里的 `title` 是这个位置（或系列）的名称，`items` 是每个系列的名称、按坐标轴格式化后的文字、原始的值、颜色和所在的行。

散点图的提示框标题默认是系列名称，`label` 可以改为每个点自己的名称，见[散点图](./scatter)。

## 突出系列

有多个系列时，指针所在的系列会突出显示，其余的变淡，提示框里其他系列的文字也变浅：

- 指针靠近某条折线（8px 以内）、在某根柱子上，或在某块面积里面时，突出这个系列。
- 散点图突出指针下的点所在的系列。

## 点击与悬停

点击柱子、数据点或饼图的一块时触发 `select` 事件，用键盘移动到某个位置后按 `Enter` 也会触发。参数 `ChartPointEvent` 和提示框显示的内容相同：

- `x` 是这个位置原本的值：类目文字、`Date` 或数字，饼图是这一块的名称。
- `items` 是这里的各个值和它们所在的行，可以用来进入明细。

提示框换到另一处内容时触发 `hover` 事件，参数和 `select` 相同。指针在同一处移动不会重复触发；数据变化让这里的内容变了时会再触发一次。离开图表、提示框收起或图表被移除时触发一次，参数是 `null`。

`hover` 适合让旁边的表格跟着图表高亮，示例见区块[经营看板](../blocks/business)。图表没有从外部设置提示框位置的接口，所以表格悬停不会让图表高亮。

`DouChartTooltip` 设置了 `disabled` 时，图表不跟随指针和键盘，也不触发 `hover`。

## 联动提示框

几个图表的 `DouChartTooltip` 设置相同的 `group`，指针移到其中一个上时，其余的图表也在同一个横轴位置显示提示框，方便对照不同指标的同一天。

- 位置按数据的值对应：类目轴按类目名，时间轴和数值轴按相同的值。某个图表没有这个位置时不显示。
- 只有指针或键盘所在的图表触发 `hover`，也只有它会读出数值。

示例见[缩放与框选 · 联动](./zoom#联动)。

## 图例

点击图例隐藏或显示对应的系列，坐标轴随之按剩下的系列重新计算。最后一个显示的系列不能隐藏。

<DocDemo src="chart/legend" />

- 鼠标移到图例上，或用键盘聚焦到图例时，对应的系列保持原样，其余的变淡。
- 按住 `Alt`（Mac 上是 `⌥`）点击图例只显示这一个系列，再点一次恢复全部。手机上长按图例效果相同，键盘聚焦到图例时按 `Alt` + `Enter`。
- 系列的 `v-model:hidden` 绑定它是否隐藏，可以设置初始状态，或在图表外控制。

饼图隐藏的是其中的块，见[饼图 · 隐藏一些块](./pie#隐藏一些块)。

## 图例的位置

`legendPlacement` 把图例放在图表下方（`'bottom'`，默认）、上方（`'top'`）或右侧（`'right'`）。

<DocDemo src="chart/legend-position" />

- 图例在上下方时最多显示三行，在右侧时最多占图表宽度的 30%，放不下的部分在图例里滚动。
- 右侧过长的名称末尾省略，悬停或用键盘聚焦时显示完整的名称。
- 图表宽度小于 480px 时（比如手机上），右侧的图例改放到下方。

## API

### Tooltip Props

| 名称        | 说明                                       | 类型               | 默认值                                   |
| ----------- | ------------------------------------------ | ------------------ | ---------------------------------------- |
| `trigger`   | 按位置显示全部系列，或只显示指针下的一个点 | `'axis' \| 'item'` | 散点图和饼图为 `'item'`，其余为 `'axis'` |
| `crosshair` | 标出当前位置的竖线（柱状图是浅色的带）     | `boolean`          | `true`                                   |
| `disabled`  | 关闭提示框，图表也不再能聚焦               | `boolean`          | `false`                                  |
| `group`     | 同名分组的图表跟随同一个横轴位置显示提示框 | `string`           | —                                        |

### Tooltip Slots

| 名称      | 说明                                                                           | 参数                                                                                        |
| --------- | ------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------- |
| `default` | 提示框的内容；`note` 是饼图隐藏了几项的说明，`active` 表示这一项的系列在指针下 | `{ title?: string, items: { name, text, value?, color?, row?, active? }[], note?: string }` |

### ChartPointEvent

`select` 和 `hover` 事件的参数。

| 属性    | 说明                                                      | 类型                 |
| ------- | --------------------------------------------------------- | -------------------- |
| `x`     | 这个位置原本的值：类目文字、`Date` 或数字；饼图是块的名称 | `unknown`            |
| `title` | 提示框的标题；矩形树图和旭日图是节点的完整路径            | `string`             |
| `items` | 这个位置的各个值，和提示框插槽的 `items` 相同             | `ChartTooltipItem[]` |
