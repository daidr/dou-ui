# 数据标签与标注

`labels` 在图上直接写出每个值，`DouChartMarker` 在图上标出参考线、区间和点。

## 数据标签

系列设置 `labels` 后，按对应数值轴的 `format` 写出每个值。

<DocDemo src="chart/labels" />

- 会和其他标签重叠，或者超出绘图区的标签不显示，所以数据很密时只显示一部分。
- 设置了标签的数值轴会在两端多留出一些空间，让最高的标签也能放下。
- 标签在系列画完之后才出现。导出的 SVG 和 PNG 里也包含标签。

## 柱子上的标签

- 柱状图的标签默认写在柱子末端外面，`label-position="inside"` 写在柱子里面，放不下的不写。
- 堆叠的柱子默认写在里面，文字颜色按柱子的颜色选择深色或浅色。
- 百分比堆叠的标签写占比。数值轴没有设置 `format` 时保留一位小数（比如 `33.3%`），刻度仍然是整数百分比。

## 线末端的标签

折线和面积图的标签写在每个点的上方，点之间的空间不够时整条线都不写。

`label-position="end"` 只在线的最后一个点旁边写一个标签，使用系列的颜色。几条线的末端靠得很近时，标签上下错开。下面用它直接写出系列名称，代替图例。

## 自定义文字

`labels` 可以传入函数，参数是一个对象，返回要写的文字；返回 `null` 或 `undefined` 时不写。

```ts
const label = ({ value, name }) => (value > 1000 ? `${name} ${value}` : null)
```

参数的各个属性见下方 [ChartDataLabel](#chartdatalabel)。饼图标签的写法见[饼图 · 标签](./pie#标签)。

## 标注

`DouChartMarker` 可以写多个，`x` 和 `y` 的写法决定画出什么：

| 写法                     | 画出                   |
| ------------------------ | ---------------------- |
| 只有 `y`                 | 一条横线，例如目标值   |
| 只有 `x`                 | 一条竖线，例如上线日期 |
| `x` 或 `y` 是 `[起, 止]` | 一段区间               |
| `x` 和 `y` 都是单个值    | 一个点                 |

`x` 的写法和横轴的数据一致：类目轴上是类目名，时间轴上是 `Date` 或日期字符串。横向图里方向随坐标轴一起转过来。

### 参考线

<DocDemo src="chart/marker-line" />

- `y` 超出数据的范围时，数值轴会延伸到它，所以目标值总能显示出来。
- 线默认是虚线，`:dashed="false"` 画成实线。
- 文字放在同色的浅底上，几个标注的文字靠得太近时自动错开。

## API

### ChartDataLabel

`labels` 函数的参数。

| 属性    | 说明                                                           | 类型       |
| ------- | -------------------------------------------------------------- | ---------- |
| `value` | 值                                                             | `number`   |
| `share` | 占比，0 到 1：百分比堆叠和饼图才有                             | `number`   |
| `low`   | 下沿的值：设置了 `y0` 的面积图才有                             | `number`   |
| `name`  | 系列的名称；饼图是这一块的名称                                 | `string`   |
| `row`   | 对应的一行数据                                                 | `ChartRow` |
| `index` | 这一行在数据里的位置；矩形树图和旭日图是节点在同级节点里的位置 | `number`   |
| `depth` | 节点所在的层级，第一层是 1：矩形树图和旭日图才有               | `number`   |

### Marker Props

| 名称     | 说明                                         | 类型                                     | 默认值      |
| -------- | -------------------------------------------- | ---------------------------------------- | ----------- |
| `x`      | 横轴上的位置，给出两端时是一段区间           | `number \| string \| Date \| [from, to]` | —           |
| `y`      | 数值，给出两端时是一段区间；数值轴会延伸到它 | `number \| [number, number]`             | —           |
| `axis`   | `y` 对应的数值轴                             | `'y' \| 'y2'`                            | `'y'`       |
| `label`  | 显示的文字                                   | `string`                                 | —           |
| `tone`   | 颜色                                         | `Tone`                                   | `'neutral'` |
| `dashed` | 参考线画成虚线                               | `boolean`                                | `true`      |
