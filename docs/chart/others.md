# 雷达图、漏斗图与仪表盘

这三种图表都不能和其他系列放在同一个图表里。

## 雷达图

`DouChartRadar` 从中心向外为每个分类画一条轴，每个系列连成一个闭合的形状，适合比较几个对象在多个方面的表现。

<DocDemo src="chart/radar" />

- 轴按数据的顺序从 12 点钟方向顺时针排列。值从中心的 0 向外增大，网格是多边形。
- 一个图表里可以有多个雷达图系列，它们共用同一组轴和刻度。`<DouChartAxis for="y">` 可以设置刻度的 `min`、`max` 和 `format`。
- 轴不超过 12 条时在每个顶点画圆点，`dots` 可以打开或关闭。
- 提示框显示指针最近的那条轴上所有系列的值。方向键沿着轴绕圈移动：右、下是下一条，左、上是上一条。

## 漏斗图

`DouChartFunnel` 把每一行画成一个环节，按数据的顺序从上到下排列，适合展示转化流程。一个图表里只能有一个漏斗图。

<DocDemo src="chart/funnel" />

- 每个环节的宽度和值成正比，最大的值占满整个宽度。
- 相邻环节之间的浅色区域表示流失的部分。
- 左边是环节名称，右边是值和转化率。转化率是这个环节占上一个环节的比例，保留一位小数。
- 提示框和数据表还显示总转化率，即占第一个环节的比例。

## 仪表盘

`DouChartGauge` 在一段弧形的轨道上显示一个值，中间写出这个值和 `name`。一个图表里只能有一个仪表盘，需要多个时放多个图表。

<DocDemo src="chart/gauge" />

- `min` 和 `max` 是轨道两端的值，默认是 `0` 和 `100`。超出范围的值画到轨道的端点，中间仍然写出原值。`min` 可以大于 `max`，这时值越小，弧线越长。
- `value` 不是数字时，中间显示“–”，轨道留空。
- `format` 设置值的写法，比如加上百分号。
- `color` 是值的弧线的颜色，可以写成值的函数，按阈值返回不同的语气色。
- 轨道默认从 `-120` 度到 `120` 度，`startAngle` 和 `endAngle` 可以改成半圆等形状，`innerRadius` 决定弧线的粗细。

默认插槽可以替换中间的内容，插槽参数是 `value` 和格式化后的 `text`。仪表盘没有图例和提示框，读屏会读出名称、值和范围。

## API

### Radar Props

| 名称             | 说明                         | 类型                                        | 默认值                  |
| ---------------- | ---------------------------- | ------------------------------------------- | ----------------------- |
| `y`              | 值：字段名，或从行取值的函数 | `string \| (row, index: number) => unknown` | —                       |
| `name`           | 系列名称                     | `string`                                    | `y` 的字段名            |
| `data`           | 这个系列自己的数据           | `object[] \| Record<string, ArrayLike>`     | 图表的 `data`           |
| `x`              | 每条轴的名称                 | `string \| (row, index: number) => unknown` | 图表的 `x`              |
| `color`          | 颜色，任意 CSS 颜色          | `string`                                    | 色板的下一个色          |
| `tone`           | 用语气色作为颜色             | `Tone`                                      | —                       |
| `dots`           | 在顶点画圆点                 | `boolean`                                   | 轴不超过 12 条时 `true` |
| `lineWidth`      | 轮廓线的宽度，单位 px        | `number`                                    | `2`                     |
| `v-model:hidden` | 隐藏系列                     | `boolean`                                   | `false`                 |

### Funnel Props

| 名称     | 说明                         | 类型                                        | 默认值         |
| -------- | ---------------------------- | ------------------------------------------- | -------------- |
| `y`      | 值：字段名，或从行取值的函数 | `string \| (row, index: number) => unknown` | —              |
| `name`   | 系列名称                     | `string`                                    | `y` 的字段名   |
| `data`   | 这个系列自己的数据           | `object[] \| Record<string, ArrayLike>`     | 图表的 `data`  |
| `x`      | 每个环节的名称               | `string \| (row, index: number) => unknown` | 图表的 `x`     |
| `color`  | 颜色，任意 CSS 颜色          | `string`                                    | 色板的下一个色 |
| `tone`   | 用语气色作为颜色             | `Tone`                                      | —              |
| `radius` | 每个环节的圆角，单位 px      | `number`                                    | `3`            |

### Gauge Props

| 名称          | 说明                                           | 类型                                  | 默认值       |
| ------------- | ---------------------------------------------- | ------------------------------------- | ------------ |
| `value`       | 显示的值                                       | `number`                              | —            |
| `min`         | 轨道起点的值                                   | `number`                              | `0`          |
| `max`         | 轨道终点的值                                   | `number`                              | `100`        |
| `name`        | 值的名称，写在值的下方，读屏时读出             | `string`                              | —            |
| `color`       | 值的弧线的颜色：CSS 颜色或语气色，或者值的函数 | `string \| (value: number) => string` | 色板的彩色   |
| `format`      | 值的写法                                       | `(value: number) => string`           | 按语言格式化 |
| `innerRadius` | 中间空洞占半径的比例，决定弧线的粗细           | `number`                              | `0.8`        |
| `startAngle`  | 轨道的起始角度，单位是度，0 是 12 点钟方向     | `number`                              | `-120`       |
| `endAngle`    | 轨道的结束角度                                 | `number`                              | `120`        |

### Gauge Slots

| 名称      | 说明                                 |
| --------- | ------------------------------------ |
| `default` | 中间的内容，参数是 `{ value, text }` |
