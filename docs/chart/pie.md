# 饼图

`DouChartPie` 用于展示各部分在整体中的占比。一个图表里只能有一个饼图，饼图不能和其他系列放在一起。

## 基础用法

`value` 是每一块的值，`label` 是每一块的名称，不写时使用图表的 `x`。

<DocDemo src="chart/pie" />

- 各块按数据的顺序从 12 点钟方向顺时针排列，小于等于 0 的值不画。
- 饼图没有坐标轴，下方的图例列出每一块。

## 颜色

每一块默认依次使用色板里的彩色，跳过第 1 个中性灰。`color` 可以给每一块指定颜色，写成字段名或函数，返回 CSS 颜色或语气色名称；返回 `neutral` 时使用中性灰，适合“其他”。

色板只有 7 种彩色，块数更多时颜色会重复，开发环境下会在控制台提示。块较多时，建议把较小的几块合并成“其他”。

## 环形图

`innerRadius` 是中间空洞占半径的比例，设置后画成环形图。默认插槽的内容显示在空洞中间，可以放合计或说明。

<DocDemo src="chart/donut" />

## 角度

`startAngle` 和 `endAngle` 设置起止的角度，单位是度。0 是 12 点钟方向，顺时针为正，默认从 `0` 到 `360`。

<DocDemo src="chart/pie-half" />

- 从 `-90` 到 `90` 画成半环，饼图按半环的大小排布，空洞里的内容放在平边上方。
- `endAngle` 要大于 `startAngle`，两者最多相差 360 度。

## 玫瑰图

`rose` 让每一块的角度相同，用半径表示值，适合比较各块的大小，比如一周中每天的订单。半径和值的平方根成正比，所以面积和值成正比。

<DocDemo src="chart/pie-rose" />

## 标签

`labels` 在饼图外面写出每一块的名称和占比，用一条线连到对应的块，饼图会相应缩小。`label-position="inside"` 在每一块里面写占比，太小的块不写。

<DocDemo src="chart/pie-labels" />

- 外面的标签一侧放不下时，较小的块不写。
- 图表较窄时，过长的名称末尾省略，占比始终完整显示。
- 留出标签的位置后饼图太小时，标签改为写在块里面。

`labels` 也可以是函数，用法见[数据标签](./labels#自定义文字)。

## 隐藏一些块

点击图例可以隐藏对应的块。`v-model:hidden` 是隐藏的各块的名称组成的数组，按 `label` 的文字匹配，所以各块的名称应当不同。

隐藏一些块之后，占比只按显示的块计算，提示框和读屏会注明隐藏了几项。

## API

### Pie Props

| 名称             | 说明                                                            | 类型                                                                | 默认值        |
| ---------------- | --------------------------------------------------------------- | ------------------------------------------------------------------- | ------------- |
| `value`          | 每一块的值：字段名，或从行取值的函数                            | `string \| (row, index: number) => unknown`                         | —             |
| `label`          | 每一块的名称                                                    | `string \| (row, index: number) => unknown`                         | 图表的 `x`    |
| `data`           | 饼图自己的数据，写法同图表的 `data`                             | `object[] \| Record<string, ArrayLike>`                             | 图表的 `data` |
| `name`           | 饼图的名称，读屏时读在最前面                                    | `string`                                                            | —             |
| `color`          | 每一块的颜色：字段名，或返回 CSS 颜色、语气色名称的函数         | `string \| (row, index: number) => string \| undefined`             | 色板的彩色    |
| `innerRadius`    | 中间空洞占半径的比例，`0` 是饼图                                | `number`                                                            | `0`           |
| `startAngle`     | 起始角度，单位是度，0 是 12 点钟方向，顺时针为正                | `number`                                                            | `0`           |
| `endAngle`       | 结束角度，单位是度                                              | `number`                                                            | `360`         |
| `rose`           | 画成玫瑰图                                                      | `boolean`                                                           | `false`       |
| `labels`         | 每一块的标签：`true` 写名称和占比（写在里面时只写占比），或函数 | `boolean \| (label: ChartDataLabel) => string \| null \| undefined` | `false`       |
| `labelPosition`  | 标签写在饼图外面，或每一块里面                                  | `'outside' \| 'inside'`                                             | `'outside'`   |
| `v-model:hidden` | 隐藏的各块的名称                                                | `string[]`                                                          | `[]`          |

### Pie Slots

| 名称      | 说明                       |
| --------- | -------------------------- |
| `default` | 显示在环形图空洞中间的内容 |
