# 缩放与框选

`DouChartZoom` 让图表可以放大查看局部，`DouChartRange` 在图表下方显示可拖动的区间条，`DouChartBrush` 用于拖动选出一段数据。

## 缩放与平移

在图表里放一个 `DouChartZoom`，再放一个 `DouChartRange` 显示全部数据的缩略图。

<DocDemo src="chart/zoom" />

- 按住 `Ctrl`（Mac 上是 `⌘`）滚动滚轮，或在触控板上双指捏合缩放。
- 放大后拖动图表平移，在触控板上左右滑动也能平移。双击复位。
- 手机上双指捏合缩放，单指左右拖动平移，上下滑动仍然滚动页面。
- 键盘聚焦图表后，`+`、`-` 键缩放，`0` 键复位。

`v-model:x` 是显示的范围，值是数据本身（时间轴上是 `Date`，类目轴上是类目名），`null` 表示全部。拖动区间条两端的手柄或中间的区域可以调整范围。

滚轮默认用来滚动页面，按住 `Ctrl` 时才缩放，页面滚过图表时不会被打断。图表占满整个页面时，可以设置 `wheel`，直接用滚轮缩放。

## 缩放数值轴

`axis="xy"` 时数值轴也可以缩放，`v-model:y` 是数值的范围。有两条数值轴时，`v-model:y` 是 `y` 轴的范围，`y2` 按同样的比例跟随。

## 联动

几个图表的 `v-model:x` 绑定同一个值，缩放和平移就会一起变化。`DouChartTooltip` 设置相同的 `group`，提示框也会跟着同一个位置。

<DocDemo src="chart/zoom-linked" />

上下排列时，给数值轴设置相同的 `labelWidth`，绘图区的左边就能对齐，同一天落在同一条竖线上。

## 框选

放一个 `DouChartBrush`，在图表上拖动就能选出一段范围，选区外的点和柱子变淡。

<DocDemo src="chart/brush" />

- `axis` 设为 `x`（默认）、`y` 或 `xy`，分别是按横轴、按数值或框出一块区域。
- 松开时触发 `select`，参数是选中的范围和落在其中的数据行。
- 选区会一直显示，按 `Esc` 或点击选区外面清除。清除时也触发 `select`，这时没有 `x`、`y`，`rows` 为空。
- `:dim="false"` 不让选区外的数据变淡。

`DouChartBrush` 的 `select` 和图表的 `select` 不同，后者是点击柱子或数据点。

## 框选的操作方式

- 手机上按住不动片刻再拖动是框选，直接滑动仍是滚动页面。
- 和 `DouChartZoom` 一起使用时，拖动是平移，按住 `Shift` 拖动是框选。
- 键盘聚焦图表后，按住 `Shift` 再按沿横轴的方向键，从当前位置开始按横轴选择。框出一块区域（`axis="xy"`）只能用指针。

## API

### Zoom Props

| 名称        | 说明                                                | 类型                       | 默认值  |
| ----------- | --------------------------------------------------- | -------------------------- | ------- |
| `axis`      | 缩放哪个方向：横轴、数值，或两者                    | `'x' \| 'y' \| 'xy'`       | `'x'`   |
| `wheel`     | 直接用滚轮缩放，不用按住 `Ctrl`                     | `boolean`                  | `false` |
| `disabled`  | 关闭缩放，显示全部                                  | `boolean`                  | `false` |
| `v-model:x` | 显示的横轴范围，`null` 表示全部                     | `[from, to] \| null`       | `null`  |
| `v-model:y` | 显示的数值范围（`axis` 含 `y` 时），`null` 表示全部 | `[number, number] \| null` | `null`  |

`from`、`to` 是数据本身：数值轴上是数字，时间轴上是 `Date`，类目轴上是类目名（两端都包含在内）。

### Range Props

| 名称      | 说明                                                  | 类型                 | 默认值 |
| --------- | ----------------------------------------------------- | -------------------- | ------ |
| `v-model` | 显示的横轴范围，和 `DouChartZoom` 的 `v-model:x` 相同 | `[from, to] \| null` | `null` |

没有 `DouChartZoom` 时，区间条也可以单独使用，只是图表本身不能用滚轮和手势缩放。

### Brush Props

| 名称        | 说明                            | 类型                       | 默认值  |
| ----------- | ------------------------------- | -------------------------- | ------- |
| `axis`      | 按横轴、按数值，或框出一块区域  | `'x' \| 'y' \| 'xy'`       | `'x'`   |
| `dim`       | 选区外的点和柱子变淡            | `boolean`                  | `true`  |
| `disabled`  | 关闭框选                        | `boolean`                  | `false` |
| `v-model:x` | 选中的横轴范围，`null` 表示没有 | `[from, to] \| null`       | `null`  |
| `v-model:y` | 选中的数值范围，`null` 表示没有 | `[number, number] \| null` | `null`  |

### Brush Events

| 名称     | 说明                                                          | 参数              |
| -------- | ------------------------------------------------------------- | ----------------- |
| `select` | 选出范围后松开，或用 `Shift` 加方向键选择时；清除选区时也触发 | `ChartBrushEvent` |

### ChartBrushEvent

| 属性     | 说明                                   | 类型                                 |
| -------- | -------------------------------------- | ------------------------------------ |
| `x`      | 选中的横轴范围                         | `[from, to]`                         |
| `y`      | 选中的数值范围                         | `[number, number]`                   |
| `rows`   | 有数据点落在选区里的行，每行只出现一次 | `object[]`                           |
| `series` | 按系列分别列出的行                     | `{ name: string, rows: object[] }[]` |
