# 手机触控

在触屏上，编辑器提供选区把手、操作工具条和符号栏。

## 选择文字

- 轻点放置光标并弹出键盘，拖动光标下方的把手移动光标。再点一下光标，弹出粘贴、全选的工具条。
- 长按选中一个词，不松手继续滑动可以扩大选区。拖动选区两端的把手调整范围，手指上方会显示放大的当前行。
- 选好后，选区上方出现剪切、复制、粘贴、全选的工具条。
- 单指在文字上滑动是滚动，不会选择文字。
- 选区、把手和工具条都由编辑器绘制，不会出现系统自带的选区和菜单。把手浮在页面上，单行的输入框也不会裁掉它们。滚动页面时，它们和文字一起移动；编辑器放在会滚动的容器里（抽屉、侧栏）时，容器滚动期间它们先隐藏，停下后再出现。

键盘弹出或变高（例如出现候选栏）时，编辑器会滚动，让光标保持在键盘上方。手指滚动页面时不会把光标拉回来。键盘的空格键拖动光标、自动更正和语音输入都可以正常使用。

## 符号栏

编辑器获得焦点时，下方会出现一条符号栏，随页面一起滚动。它不贴着键盘，所以不受各家浏览器键盘样式的影响。编辑器很高、下方不在视野内时，符号栏停在视野底部；键盘弹出后，还没移动过的符号栏会移到键盘上方，之后不再跟着键盘。

按住左端的拖动柄，可以把符号栏移到页面上任意位置。用键盘时，焦点在拖动柄上按方向键也能移动它，按住 `Shift` 每次移动更多。

符号栏中间可以横向滑动，包含 `Tab`、各种括号、常用符号以及撤销、重做。右端是移动光标的摇杆：按下后放大，朝哪个方向推，光标就往哪边移动，推得越远移动越快，松开后恢复原样。焦点在摇杆上时，也可以用方向键移动光标。

## 自定义按键

`keys` 传入数组改写左侧的按键。字符串表示输入它本身的按键；`defaultCodeKeys` 是默认的按键，可以在它的基础上增加：

```ts
import { codeCommands, defaultCodeKeys } from '@dou-ui/code'

const keys = [
  ...defaultCodeKeys,
  { label: '=>', text: ' => ' },
  { label: '//', command: codeCommands.toggleComment, ariaLabel: '切换注释' },
]
```

`text` 是按下时输入的文字，括号和引号会像键盘输入一样自动补全；`command` 用于输入以外的操作。

## API

### CodeKeys Props

| 名称       | 说明                               | 类型                    | 默认值            |
| ---------- | ---------------------------------- | ----------------------- | ----------------- |
| `editor`   | 绑定的编辑器实例                   | `CodeEditorExpose`      | —                 |
| `keys`     | 可以滑动的按键；末尾的摇杆始终存在 | `(CodeKey \| string)[]` | `defaultCodeKeys` |
| `messages` | 改写按键的名称                     | `Partial<CodeMessages>` | —                 |

### CodeKey

| 名称        | 说明                                       | 类型          |
| ----------- | ------------------------------------------ | ------------- |
| `label`     | 按键上显示的文字；有 `icon` 时作为按键名称 | `string`      |
| `text`      | 按下时输入的文字，默认是 `label`           | `string`      |
| `command`   | 按下时执行的命令，代替输入                 | `CodeCommand` |
| `icon`      | 代替文字显示的图标                         | `Component`   |
| `repeat`    | 按住时连续触发                             | `boolean`     |
| `ariaLabel` | 读屏读出的名称                             | `string`      |
