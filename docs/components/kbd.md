## 尺寸

`sm`（18px）用于正文与菜单里，`md`（20px，默认）单独出现时使用。

## API

### Props

| 名称   | 说明 | 类型           | 默认值 |
| ------ | ---- | -------------- | ------ |
| `size` | 尺寸 | `'sm' \| 'md'` | `'md'` |

### Slots

| 名称      | 说明 |
| --------- | ---- |
| `default` | 按键 |
