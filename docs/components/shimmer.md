# Shimmer 微光文字

一道光从文字上扫过，用于"正在生成""正在搜索"这类进行中的状态。

## 基础用法

`active` 控制是否显示扫光，关闭后按普通文字显示。`duration` 是扫过一次的秒数，默认 2 秒。系统开启了减弱动态效果时，只显示为浅色文字。

## API

### Props

| 名称       | 说明           | 类型      | 默认值   |
| ---------- | -------------- | --------- | -------- |
| `active`   | 是否显示扫光   | `boolean` | `true`   |
| `duration` | 扫过一次的秒数 | `number`  | `2`      |
| `as`       | 渲染的元素     | `string`  | `'span'` |

### Slots

| 名称      | 说明 |
| --------- | ---- |
| `default` | 文字 |
