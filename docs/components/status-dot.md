# StatusDot 状态点

一个小圆点加一段文字，一眼看出某样东西现在的状态：在线、运行中、出错。正在发生的状态可以加上缓缓散开的涟漪。

## 基础用法

`tone` 决定圆点的颜色。默认的 `neutral` 是安静的灰色，适合离线、空闲这类不需要注意的状态；只有状态本身有含义时才用彩色。文字写在默认插槽里，颜色和字号跟随所在的位置。

<DocDemo src="status-dot/basic" />

## 涟漪

`ripple` 让一圈同色的涟漪从圆点向外散开并淡出，用来提示“这件事正在发生”：直播中、构建中、告警还没处理。同一屏里有涟漪的点应该是少数，否则就没人能分清哪个更要紧。

开启「减弱动态效果」或设置 `data-dou-motion` 为 `reduce`、`none` 时，涟漪停下来，变成一圈静止的光晕，状态仍然可以分辨，见[动效](/guide/motion)。

<DocDemo src="status-dot/ripple" />

## 尺寸

`size` 有 `sm`、`md`、`lg` 三档，圆点直径分别是 6、8、10px。

<DocDemo src="status-dot/size" />

## 大量状态点

涟漪只用 CSS 动画，而且只改变 `transform` 和 `opacity`，浏览器可以在合成线程里完成，不运行脚本，也不触发重排。一页放上百个状态点也不会拖慢页面。下面是一个虚构机房的 96 个节点，宕机和负载偏高的节点带涟漪。

<DocDemo src="status-dot/many" />

涟漪会画到圆点外面，最大约为圆点直径的 2.6 倍。放在 `overflow: hidden` 的容器边缘时，给它留出一点空间。

## 读屏

圆点本身只是装饰。旁边有文字时，读屏读出文字；只有一个圆点时，用 `label` 给出它的含义，如“在线”，没有 `label` 的圆点对读屏隐藏。颜色不是唯一的信息来源：在只放圆点的地方，再配一个 `title` 或旁边的说明，让分不清颜色的人也能知道状态。

## API

### Props

| 名称     | 说明                               | 类型                                                           | 默认值      |
| -------- | ---------------------------------- | -------------------------------------------------------------- | ----------- |
| `tone`   | 状态的语气色，`neutral` 为灰色     | `'neutral' \| 'primary' \| 'success' \| 'warning' \| 'danger'` | `'neutral'` |
| `size`   | 圆点直径：6、8、10px               | `'sm' \| 'md' \| 'lg'`                                         | `'md'`      |
| `ripple` | 显示涟漪；减少动效时为静止的光晕   | `boolean`                                                      | `false`     |
| `label`  | 没有文字时读屏读出的内容，如“在线” | `string`                                                       | —           |

### Slots

| 名称      | 说明           |
| --------- | -------------- |
| `default` | 圆点旁边的文字 |

### CSS 变量

| 变量                     | 说明             |
| ------------------------ | ---------------- |
| `--dou-status-dot-size`  | 圆点直径         |
| `--dou-status-dot-color` | 圆点和涟漪的颜色 |
| `--dou-status-dot-gap`   | 圆点与文字的间距 |
