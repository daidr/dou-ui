# StreamText 流式文字

平滑显示逐步到达的文字，用于模型的流式回答。

## 基础用法

把目前收到的全部文字传给 `content`，还有内容要来时 `streaming` 设为 `true`。新增的部分会逐字显示出来，末尾带一个闪烁的光标；`streaming` 变为 `false` 并且文字全部显示完后触发 `done`。

挂载时如果 `streaming` 为 `false`，比如显示历史消息，文字会直接全部显示。

## 显示速度

`speed` 是每秒最少显示的字数，默认 40。积压的文字较多时会自动加快，大约半秒内追上，所以不会落后太多。`smooth` 设为 `false` 时不做平滑，收到多少显示多少。

如果新的 `content` 不是在原来的基础上追加，而是被替换了，会从两者相同的部分接着显示。

## 自定义渲染

默认插槽的参数里有已经显示的文字 `text` 和是否结束 `done`，可以交给 Markdown 渲染器或者自己排版。用插槽渲染块级内容时，可以关掉 `caret`，换成别的提示。

## API

### Props

| 名称        | 说明                     | 类型      | 默认值  |
| ----------- | ------------------------ | --------- | ------- |
| `content`   | 目前收到的文字           | `string`  | `''`    |
| `streaming` | 是否还有内容要来         | `boolean` | `false` |
| `smooth`    | 是否逐字显示新增的文字   | `boolean` | `true`  |
| `speed`     | 每秒最少显示的字数       | `number`  | `40`    |
| `caret`     | 输出过程中在末尾显示光标 | `boolean` | `true`  |
| `as`        | 渲染的元素               | `string`  | `'div'` |

### Events

| 名称   | 说明                             | 参数 |
| ------ | -------------------------------- | ---- |
| `done` | 文字全部显示完，并且不再有新内容 | —    |

### Slots

| 名称      | 说明                                      |
| --------- | ----------------------------------------- |
| `default` | 渲染已显示的文字，参数为 `{ text, done }` |

### Exposes

| 名称    | 说明                     | 类型         |
| ------- | ------------------------ | ------------ |
| `flush` | 立即显示已收到的全部文字 | `() => void` |
