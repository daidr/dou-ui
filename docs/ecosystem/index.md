# 生态系统

除了 `dou-ui` 本身，DouUI 还提供几个单独安装的包。块编辑器、流程编辑器、甘特图、电子表格、图表、表单设计器、代码编辑器、数据透视和仪表盘是功能较多的大型组件，图标库和 Nuxt 模块是配套使用的包。点击卡片查看对应的文档。图标库的文档在顶栏的“图标”下，Nuxt 模块的文档在“集成”下。

各个包的组件都可以自动导入，连同样式一起，不用手写 `import`，见 [Vite](/integrations/vite#生态系统的包) 与 [Nuxt](/integrations/nuxt#生态系统的包)。
