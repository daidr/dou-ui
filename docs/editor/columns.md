# 分栏

`columns` 扩展把几个块并排放成几栏，默认包含在 `editorKit` 里。在斜杠菜单里输入“分栏”，在旁边的面板里选择栏数（2 到 5 栏）插入。

不需要分栏时，用 `editorKit({ columns: false })` 关掉。

## 插入

斜杠菜单选中“分栏”时，右侧会出现选择栏数的面板，指针移到第几根竖条上就是几栏，点击插入。也可以用键盘：`←` `→` 选择栏数，`Enter` 插入。直接点“分栏”这一项插入两栏。

在空的正文里插入时，分栏会替换这一行；在有文字的块里插入时，放在这个块的下面。插入后光标在第一栏里，每一栏开始时是一个空段落。分栏是所在层级的最后一个块时，下面会多出一个空段落，方便接着写。

## 编辑

每一栏里可以放任意的块，包括列表、表格、图片，也可以缩进。编辑时指针移到分栏上，各栏会显示虚线边框，空的栏也能看出位置。在栏里编辑时：

| 操作                     | 作用                                                 |
| ------------------------ | ---------------------------------------------------- |
| 在一栏开头按 `Backspace` | 文字留在这一栏里；这一栏只剩一个空段落时，删除这一栏 |
| 在一栏末尾按 `Delete`    | 不会把下一栏的文字拉上来                             |
| 在分栏后面的块上按 `Tab` | 不会放进分栏                                         |
| `Shift + Tab`            | 最多回到这一栏的顶层，不会移出这一栏                 |

一栏里的块全部删除或移走后，这一栏会自动去掉；只剩一栏时，分栏也会去掉，剩下的块回到原来的位置。

## 拖动

栏里的块和其他块一样，按住左侧的把手拖动，可以在栏之间移动，也可以拖出分栏。栏里的块只显示拖动把手，放在两栏之间的空白处。

拖到两栏之间的空白处，或者第一栏左侧、最后一栏右侧时，会出现一条竖线，放下后在这里新建一栏，宽度是其他栏的平均值。一组分栏最多 5 栏，满了以后不再出现竖线。

要移动、复制或删除整组分栏，打开栏里任意一个块的菜单，选择“选中整个分栏”，再拖动把手或按 `Delete`。跨栏选中文字后按 `Esc`，选中的也是整组分栏。

## 栏宽

指针移到两栏之间的空白处正中时，会出现一条竖线，左右拖动可以调整这两栏的宽度，松开后才写入文档，撤销一次即可恢复。双击这条竖线，这组分栏的每一栏恢复一样宽。每一栏最窄 96px。

## 小屏幕

分栏所在的区域窄于 480px 时，各栏改为上下排列，按第一栏到最后一栏的顺序阅读。这时不显示调整栏宽的竖线，拖动时也不会新建一栏。在手机上，栏里的块和其他块一样，光标所在的块旁边会出现拖动把手。

## 数据

分栏是一个 `columns` 块，每一栏是它 `children` 里的一个 `column` 块，栏里的块放在 `column` 块的 `children` 里：

```ts
const block: PartialBlock = {
  type: 'columns',
  children: [
    { type: 'column', props: { width: 2 }, children: [{ content: '左边' }] },
    { type: 'column', children: [{ content: '右边' }] },
  ],
}
```

`width` 是这一栏占的比例，和同组其他栏的 `width` 相比，省略时为 `1`。上面的例子里，左栏是右栏的两倍宽。用比例而不是像素保存，编辑器宽度变化时各栏一起缩放；协同编辑时两个人同时调整不同的栏，两边的修改都会保留。

传入的数据不符合上面的结构时，编辑器在下一次修改块的结构时整理：不在分栏里的 `column` 换成它的子块，没有子块的栏被去掉，少于两栏的分栏换成它的子块，直接放在 `columns` 里的其他块移到前一栏。

导出 HTML 时，分栏写成一个 `display: flex` 的 `div`，每一栏是其中按比例分宽的 `div`，导入时可以读回分栏。Markdown 没有分栏，导出时各栏的内容按顺序依次写出。
