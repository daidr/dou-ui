# 分栏

`columns` 扩展把几个块并排放成几栏，默认包含在 `editorKit` 里。在斜杠菜单里输入“分栏”，再选择栏数（2 到 5 栏）插入：桌面上在旁边的面板里选，手机上在这一项下面展开后选。

<DocDemo src="editor/columns" column />

示例里第一栏的 `width` 是 `2`，比第二栏宽一倍；打开“窄屏”时编辑器只有 400px 宽，两栏改为上下排列。

不需要分栏时，用 `editorKit({ columns: false })` 关掉。

## 插入

斜杠菜单选中“分栏”时，右侧会出现选择栏数的面板，指针移到第几根竖条上就是几栏，点击插入。直接点“分栏”这一项插入两栏。

用键盘时，`→` 进入面板并逐个增加栏数，`←` 逐个减少，回到“分栏”这一项后再按 `←` 移动光标；`Enter` 插入当前的栏数，停在“分栏”这一项上时插入两栏。

在手机上，选择栏数的面板不在旁边弹出，而是在“分栏”这一项下面展开：第一次点“分栏”展开竖条，前两根亮起，表示直接再点“分栏”插入两栏；点第几根竖条就插入几栏。菜单靠近屏幕底部时，页面会向上滚动，让展开的竖条完整显示。

在空段落里插入时，分栏替换这个段落；在有文字的块里插入时，放在这个块的下面。插入后光标在第一栏里，每一栏开始时是一个空段落。分栏是所在层级的最后一个块时，下面会多出一个空段落，方便接着写。

分栏里不能再插入分栏：光标在栏里时，斜杠菜单不提供“分栏”。粘贴或拖进栏里的分栏会被展开，它的各栏内容依次放进这一栏。

## 编辑

每一栏里可以放分栏以外的任意块，包括列表、表格、图片，也可以缩进。编辑时指针移到分栏上，各栏会显示虚线边框，空的栏也能看出位置。在栏里编辑时：

| 操作                               | 作用                                                 |
| ---------------------------------- | ---------------------------------------------------- |
| 在一栏开头按 `Backspace`           | 文字留在这一栏里；这一栏只剩一个空段落时，删除这一栏 |
| 在一栏末尾按 `Delete`              | 不会把下一栏的文字拉上来                             |
| 在一栏第一行按 `↑`、最后一行按 `↓` | 光标移到整组分栏上方或下方的块                       |
| 在分栏后面的块上按 `Tab`           | 不会放进分栏                                         |
| `Shift + Tab`                      | 最多回到这一栏的顶层，不会移出这一栏                 |
| 栏里第一个块按 `Mod + Shift + ↑`   | 把这个块移到整组分栏的上方                           |
| 栏里最后一个块按 `Mod + Shift + ↓` | 把这个块移到整组分栏的下方                           |
| 在不能缩进的地方按 `Tab`           | 焦点移到这一栏旁边调整栏宽的竖线，见[栏宽](#栏宽)    |

从一栏拖选文字到另一栏，或者从分栏外拖选到栏里时，选中的是整组分栏（以及选区经过的其他块），而不是跨栏的一段文字，所以删除或输入不会把几栏的文字连在一起。

一栏里的块全部删除或移走后，这一栏会自动去掉；只剩一栏时，分栏也会去掉，剩下的块回到原来的位置。

## 拖动

栏里的块和其他块一样，按住把手拖动，可以在栏之间移动，也可以拖出分栏。栏里的块只显示拖动把手，放在这一栏左侧的空白处。

拖到两栏之间的空白处、第一栏左侧，或者最后一栏靠右边缘的地方时，会出现一条竖线，放下后在这里新建一栏，宽度是其他栏的平均值。一组分栏最多 5 栏，满了以后不再出现竖线。

要移动、复制或删除整组分栏，打开栏里任意一个块的菜单，选择“选中整个分栏”，再拖动把手或按 `Delete`。跨栏选中、或者选中一栏的块后按 `Shift + ↑` `Shift + ↓` 越过这一栏的边缘时，选中的也是整组分栏。

## 栏宽

指针移到两栏之间的空白处正中时，会出现一条竖线，左右拖动可以调整这两栏的宽度。拖动时栏宽跟着变化，松开后写入文档，撤销一次即可恢复；拖动中按 `Esc` 取消，两栏恢复拖动前的宽度。双击这条竖线，这组分栏的每一栏恢复一样宽。每一栏最窄 96px。

用键盘时，光标在栏里、按 `Tab` 不能缩进时，焦点移到这一栏旁边的竖线上，`←` `→` 每次移动两栏合计宽度的 5%，`Esc` 或 `Shift + Tab` 回到正文。读屏会读出左边这一栏占两栏的百分比。

在触屏上，先轻点两栏之间空白处的正中，出现竖线后再按住拖动。栏里块的菜单里也有“平分栏宽”，各栏宽度不一样时出现。

两栏之间的空白宽 48px，触屏上 32px，由 CSS 变量 `--dou-editor-column-gap` 决定，可以在编辑器或外层元素上改。

## 小屏幕

分栏所在的区域窄于 480px 时，各栏改为上下排列，按第一栏到最后一栏的顺序阅读。这时不显示调整栏宽的竖线，拖动时也不会新建一栏。在手机上，栏里的块和其他块一样，光标所在的块旁边会出现拖动把手。

## 读屏

每一栏读作“第 1 栏，共 2 栏”这样的名称，文字来自 `messages.columns.column`。

## 数据

分栏是一个 `columns` 块，每一栏是它 `children` 里的一个 `column` 块，栏里的块放在 `column` 块的 `children` 里：

```ts
const block: PartialBlock = {
  type: 'columns',
  children: [
    { type: 'column', props: { width: 2 }, children: [{ content: '左边' }] },
    { type: 'column', children: [{ content: '右边' }] },
  ],
}
```

`width` 是这一栏占的比例，和同组其他栏的 `width` 相比，省略时为 `1`。上面的例子里，左栏是右栏的两倍宽。用比例而不是像素保存，编辑器宽度变化时各栏一起缩放；协同编辑时两个人同时调整不同的栏，两边的修改都会保留。

用代码插入时，`insertBlocks` 和 `updateBlock` 的 `children` 里没有子块的 `columns` 块，会按 `props.count`（2 到 5，省略时为 2）生成几个空栏，和从斜杠菜单插入一样：

```ts
editor.value!.insertBlocks([{ type: 'columns', props: { count: 3 } }])
```

分栏不能放进栏里：用 `insertBlocks` 插到栏里的分栏会被展开，它的各栏内容留在这一栏，返回的 id 找不到对应的块（`getBlock` 返回 `null`），开发环境下控制台会给出提示。

`v-model` 和 `setBlocks` 传入的数据按原样载入，不会补出空栏。不符合上面结构的分栏，载入时按原样显示，导出的也是原样；编辑器在下一次修改块的结构时才整理：不在分栏里的 `column` 换成它的子块，没有子块的栏被去掉，少于两栏的分栏换成它的子块，直接放在 `columns` 里的其他块移到前一栏，栏里的分栏换成它的各栏内容。保存或载入前可以用 `checkDocument` 检查，这些情况都会报告为 `invalid-columns`，见[文档数据](./data)。

导出 HTML 时，分栏写成一个 `display: flex` 的 `div`，每一栏是其中按比例分宽的 `div`，页面较窄时各栏换行，上下排列；导入时可以读回分栏。Markdown 没有分栏，导出时各栏的内容按顺序依次写出。
