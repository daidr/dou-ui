# 快捷操作

块编辑器的大部分操作都可以用键盘完成。下表中的 `Mod` 在 macOS 上是 `⌘`，在其他系统上是 `Ctrl`。

## Markdown 快捷输入

在块的开头输入下面的标记，再输入空格，块会转换成对应的类型：

| 输入             | 转换为                   |
| ---------------- | ------------------------ |
| `#`、`##`、`###` | 一到三级标题             |
| `-`、`*` 或 `+`  | 无序列表                 |
| `1.` 或 `1)`     | 有序列表                 |
| `[]` 或 `[x]`    | 待办事项，`[x]` 为已完成 |
| `>`              | 引用                     |

在块的开头输入 <code>```</code> 转换为代码块（不需要空格）；在空块里输入 `---` 换成分隔线。

在文字中输入下面的写法，会去掉标记并设置格式：

| 输入         | 格式     |
| ------------ | -------- |
| `**文字**`   | 粗体     |
| `*文字*`     | 斜体     |
| `~~文字~~`   | 删除线   |
| `` `文字` `` | 行内代码 |

## 编辑

| 按键                    | 作用                                             |
| ----------------------- | ------------------------------------------------ |
| `Enter`                 | 拆分出新块；列表和待办会延续，空的列表项变回正文 |
| `Shift+Enter`           | 块内换行                                         |
| `Backspace`（块的开头） | 先把块变回正文，再与上一个块合并                 |
| `Tab` / `Shift+Tab`     | 增加或减少缩进；在代码块里插入两个空格           |
| `Mod+Enter`             | 离开代码块，在下方新建正文                       |
| `Mod+Z` / `Mod+Shift+Z` | 撤销 / 重做                                      |
| `/` 或 `、`             | 打开块菜单（中文输入法下 `/` 键输入的是 `、`）   |

## 格式

| 按键          | 作用     |
| ------------- | -------- |
| `Mod+B`       | 粗体     |
| `Mod+I`       | 斜体     |
| `Mod+U`       | 下划线   |
| `Mod+Shift+S` | 删除线   |
| `Mod+E`       | 行内代码 |
| `Mod+K`       | 编辑链接 |
| `Mod+Shift+L` | 左对齐   |
| `Mod+Shift+E` | 居中     |
| `Mod+Shift+R` | 右对齐   |

按住 `Mod` 点击链接，会在新标签页打开，见[打开链接](./#打开链接)。对齐只对正文、标题和引用生效；光标在其他块里时，这三个快捷键不做任何事，也不会交给浏览器（`Mod+Shift+R` 在浏览器里是强制刷新）。

## 查找和替换

| 按键                              | 作用                                 |
| --------------------------------- | ------------------------------------ |
| `Mod+F`                           | 查找；选中了一行内的文字时用它来查找 |
| `Ctrl+H`（macOS 为 `⌘+Option+F`） | 替换                                 |
| `F3` / `Mod+G`（加 `Shift` 反向） | 下一个、上一个结果                   |
| `Esc`                             | 关闭查找面板                         |

面板停在编辑器右上角，页面滚动时也留在视野里。所有结果都会标上底色，当前这一个多一圈描边。查找框里可以切换区分大小写、全词匹配和正则表达式，用正则时替换内容可以用 `$1`、`$<name>` 引用分组。结果不会跨块；用代码编辑器显示的代码块（`codeEditorBlock`）有自己的查找，不在这里查。替换和全部替换各算一步撤销。只读的编辑器只能查找。当前结果被面板挡住时（比如在第一行），面板会往下让开。

组件实例的 `openSearch()` 用代码打开面板，可以带上查询，比如 `openSearch({ search: '上海' })`。手机等触屏设备没有这些按键，需要时自己放一个按钮调用它。应用有自己的搜索、或者想用浏览器自带的查找时，把 `searchable` 设为 `false`，这些按键就交还给浏览器。面板上的文字在 [ConfigProvider](../components/config-provider) 语言包的 `findReplace` 里。

焦点在面板里时，`Enter` / `Shift+Enter` 移到下一个、上一个结果，替换框里 `Enter` 替换当前这一个、`Mod+Enter` 全部替换，按键和 [FindReplace](../components/find-replace) 一致。

## 转换块

| 按键              | 转换为       |
| ----------------- | ------------ |
| `Mod+Alt+0`       | 正文         |
| `Mod+Alt+1` ~ `3` | 一到三级标题 |
| `Mod+Shift+7`     | 有序列表     |
| `Mod+Shift+8`     | 无序列表     |
| `Mod+Shift+9`     | 待办事项     |

## 选中整块

按 `Esc` 选中光标所在的块，之后可以对整块操作：

| 按键                          | 作用                         |
| ----------------------------- | ---------------------------- |
| `↑` / `↓`                     | 选中上一个或下一个块         |
| `Shift+↑` / `Shift+↓`         | 扩大或缩小选中范围           |
| `Backspace` / `Delete`        | 删除选中的块                 |
| `Mod+D`                       | 复制选中的块                 |
| `Mod+Shift+↑` / `Mod+Shift+↓` | 上移或下移                   |
| `Tab` / `Shift+Tab`           | 调整缩进                     |
| `Mod+C` / `Mod+X`             | 复制或剪切                   |
| `Enter`                       | 回到编辑，光标在块的末尾     |
| `Esc`                         | 取消选中                     |
| 直接输入文字                  | 取消选中，在块的末尾继续输入 |

`Mod+D` 和 `Mod+Shift+↑/↓` 在编辑文字时也可以使用，作用于光标所在的块。拖动块时按 `Esc` 可以取消。
