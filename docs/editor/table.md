# 表格

`table` 扩展提供表格块，默认包含在 `starterKit` 里。在斜杠菜单里输入“表格”插入一个 3 × 3 的表格，第一行是表头。也可以从网页或表格软件复制表格粘贴进来。

<DocDemo src="editor/table" column />

不需要表格时，用 `starterKit({ table: false })` 关掉。

## 编辑

| 操作                  | 作用                                             |
| --------------------- | ------------------------------------------------ |
| `Tab` / `Shift + Tab` | 移到下一格 / 上一格；在最后一格按 `Tab` 新增一行 |
| `Enter`               | 移到下一行的同一列；在最后一行新增一行           |
| `Shift + Enter`       | 在格子里换行                                     |
| 方向键                | 在格子边缘时移到相邻的格子                       |
| 按住鼠标拖过多个格子  | 选中一块矩形区域，可以整体加格式、清空、复制     |

格子里是一段带格式的文字，可以加粗、加链接、提及，但不能放列表、图片等块。粘贴的表格里如果有这些内容，会转成文字，每段一行。

## 行和列

鼠标移到某一格时，这一列的上方和这一行的左侧各出现一个把手。点击把手选中整列或整行，并打开菜单：

- 在左侧、右侧（上方、下方）插入
- 左移、右移（上移、下移）
- 对齐方式（只有列有）
- 设为表头：第一行可以设为表头行，第一列可以设为表头列
- 清空内容、删除

按住把手拖动，可以把整行或整列移到别的位置，拖动时有一条线标出放下的位置。被合并在一起的行（列）会一起移动，也不能放进别的合并区域中间。

表格右侧和下方的“＋”分别新增一列、一行。拖动列的右边线可以调整列宽。

在手机上，点一下格子，把手就会出现在这个格子所在的行和列上；把手和“＋”按钮的触摸区域比看到的更大。手机上不能拖动调整列宽，以免滚动表格时误触。

## 合并单元格

选中一块矩形区域后，区域上方出现工具栏，点击“合并单元格”。各格的文字按顺序放进合并后的格子，每格一行。光标在合并后的格子里时，可以“取消合并”。

在合并区域中间插入行或列时，合并区域随之变大；删除其中的行或列时随之缩小。移动行或列时，被合并在一起的行（列）会一起移动。

## 文档中的数据

表格的内容放在块的 `rows` 字段里，`content` 为空数组：

```ts
{
  type: 'table',
  props: {
    headerRow: true,
    headerColumn: false,
    columns: [{ id: 'c1', width: 140 }, { id: 'c2', align: 'right' }],
  },
  content: [],
  rows: [
    { id: 'r1', cells: [{ content: [{ type: 'text', text: '门店' }] }, { content: [...] }] },
    { id: 'r2', cells: [{ content: [...], colspan: 2 }, { content: [] }] },
  ],
  children: [],
}
```

| 字段                 | 说明                                                        |
| -------------------- | ----------------------------------------------------------- |
| `props.headerRow`    | 第一行是否是表头，默认 `true`                               |
| `props.headerColumn` | 第一列是否是表头，默认 `false`                              |
| `props.columns`      | 每一列的 `id`、宽度 `width`（px，不设时自动）和对齐 `align` |
| `rows[].id`          | 行的 id，编辑过程中保持不变                                 |
| `rows[].cells`       | 这一行的格子，`content` 与块的 `content` 相同               |
| `colspan`、`rowspan` | 合并单元格，写在合并区域左上角的格子上                      |

被合并区域盖住的格子仍然留在 `cells` 里，内容为空，所以每一行的格子数都等于列数，可以按行列下标取格子。传入时格子的 `content` 可以写成字符串，`rows` 省略时得到一个空的 3 × 3 表格。

## 导入与导出

HTML 写成 `<table>`，表头放在 `<thead>` 里用 `<th>`，列宽写在 `<colgroup>`，合并单元格写成 `colspan`、`rowspan`，对齐写在格子的 `text-align` 上。

Markdown 写成 GitHub 表格，对齐写在分隔行里（`:-:`、`--:`）。GitHub 表格必须有表头行，所以没有表头的表格也会把第一行写成表头；表头列、列宽和合并单元格只保存在 HTML 里，合并单元格导出 Markdown 时被盖住的位置留空。
