# 折叠块与提示块

折叠块和提示块都包含在 `starterKit` 中，在块菜单里输入“折叠块”或“提示块”插入。

<DocDemo src="editor/toggle-callout" column />

## 折叠块

折叠块由一行标题和下面的子块组成，点击标题前的箭头展开或收起子块。

- 在展开的折叠块标题末尾按 `Enter`，会在里面新建第一个子块；在收起的折叠块标题末尾按 `Enter`，会在下面新建一个折叠块。
- 在紧跟折叠块的块上按 `Tab`，可以把它放进折叠块。
- 光标移到收起的子块里时（例如用方向键或撤销），折叠块会自动展开。

展开和收起只影响当前看文档的人，不会修改文档：`v-model` 的数据里没有展开状态，只读时也可以展开，协同编辑时每个人各自展开。打开文档时，折叠块都是收起的；编辑过程中新建的折叠块默认展开。

## 提示块

提示块用带颜色的底色和图标突出一段文字。点击图标可以选择语气：

| `tone`    | 说明                 |
| --------- | -------------------- |
| `info`    | 说明，中性色，默认值 |
| `tip`     | 提示，成功色         |
| `warning` | 注意，警告色         |
| `danger`  | 警告，危险色         |

语气保存在块的 `props.tone` 中。

## 去掉这两种块

不需要时，可以在 `starterKit` 中去掉：

```ts
starterKit({ toggle: false, callout: false })
```
