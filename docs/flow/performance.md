# 大型流程

编辑器只画看得见的部分，所以几百个节点也能流畅地平移和缩放。下面是 500 个节点、800 多条连线。例子把 `minZoom` 调到 0.05，这样“适应画布”能缩到看见全部节点；默认最小是 0.1。

## 只画视野里的内容

节点和连线离开视野 200px 以外就不再渲染，回到视野时重新画出。有几种节点会一直保留：

- 还没有测量过尺寸的节点。所以第一次挂载时全部节点都会画一遍，测量完成后才开始省略。
- 选中的节点，这样拖动和工具栏不受影响。
- 获得焦点的节点。`Tab` 切换到视野外的节点时，会先把它画出来再移到视野里。

尺寸测量的结果会保留，所以小地图、`fit()` 和整理都能照常算出视野外节点的位置。读屏只能读到视野里的节点，用 `Tab` 仍然可以按顺序走过全部节点。

## 缩小后的简化画法

缩放比例低于 `simpleZoom`（默认 0.4）时，节点只画外框和名字，端口和节点里的内容都不再渲染，连线标签也不显示。这时仍然可以选中、拖动和删除节点；放大回来后恢复原样。`simpleZoom` 设为 `0` 时不简化。

`simple` 插槽可以换掉外框里的内容：

```vue
<DouFlowEditor v-model="doc" :simple-zoom="0.3">
  <template #simple="{ node }">
    <MyStatusDot :status="node.data.status" />
    {{ node.data.label }}
  </template>
</DouFlowEditor>
```

外框里的文字按缩放比例放大，屏幕上大约保持 12px，最大是画布上的 40px。缩到 0.2 以下时名字只有几像素高，只画外框。

## 测量结果

用仓库里的 `bun run bench flow flow-zoomed-out --n=500` 可以自己跑。在同一台机器上，500 个节点：

| 情况         | 只画视野之前 | 现在  |
| ------------ | ------------ | ----- |
| 首次挂载     | 1030ms       | 309ms |
| 滚轮平移一次 | 387ms        | 23ms  |
| 页面元素数   | 8903         | 1279  |
| 内存         | 20.9MB       | 8.1MB |

## API

| 名称         | 说明                                                   | 类型                           | 默认值 |
| ------------ | ------------------------------------------------------ | ------------------------------ | ------ |
| `simpleZoom` | 低于这个缩放比例时只画节点的外框和名字，`0` 表示不简化 | `number`                       | `0.4`  |
| `#simple`    | 简化时节点外框里的内容，默认是节点的名字               | `(props: { node }) => VNode[]` | —      |
