# 布局

字段排在一个栅格里，宽度按表单自身的宽度变化。

## 栅格

<DocDemo src="form-builder/layout" column />

- 默认 12 列，由描述的 `columns` 修改；
- 每个节点的 `span` 是它占的列数，不写时占满一行；
- `span` 可以按宽度变化，写成 `{ sm: 6, lg: 4 }`，含义和 `DouGrid` 一样：每个断点从它的宽度开始生效，直到更大的断点接手，`base` 是最窄时的值。

## 断点

和 `DouGrid` 不同，这里的断点看的是表单自身的宽度，不是窗口宽度。同一份描述放在宽页面里是两列，放进窄的抽屉或手机屏幕就自动变成一列。

表单比页面窄，所以断点也小一些：

| 断点 | 表单宽度 |
| ---- | -------- |
| `sm` | 480px    |
| `md` | 640px    |
| `lg` | 800px    |
| `xl` | 960px    |

因为要按自身宽度变化，表单总是占满所在的行，在横向排列的 flex 容器里也一样。需要窄一些时给它设 `max-width`。

## 分组

`section` 是一个带标题的分组，有自己的栅格，`columns` 默认和表单一样。它本身也用 `span` 决定在外层占多宽。`bordered: true` 给分组加上边框。

## 标签位置

`layout` 和 `DouForm` 一样有三种：

- `vertical`：标签在上；
- `horizontal`：标签在左，宽度由 `labelWidth` 决定，默认 96px；表单窄于 480px 时旁边放不下，标签自动回到字段上方；
- `inline`：排成一行，常用于筛选栏，这时 `span` 不起作用。

标签页、分步和列表见[标签页、分步与列表](./structure)。
