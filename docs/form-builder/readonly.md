# 只读展示

`readonly` 把字段的值显示成文字，适合详情页、审批单这类只看不填的场景。

## 基础用法

<DocDemo src="form-builder/readonly" column />

- 选择类字段显示选项的文字而不是值，开关显示“是”“否”；
- 日期按当前语言的格式显示，密码显示成圆点；
- 没有值的字段显示“—”。

只读时不显示必填标记和字段说明，列表没有添加、删除和拖动，分步表单把每一步依次排开、各自带着标题。

## 和 model 的关系

只读时渲染器不会写 `model`：缺少的字段不会填上默认值，公式字段显示的是现算的结果。切回可编辑时才填上默认值，所以同一个 `model` 可以先展示、再编辑。

## 自定义字段的显示

自定义字段类型用 `format(value, props, context)` 决定显示的文字，需要文字以外的样子时提供 `readonlyComponent`，见[只读时的显示](./fields#只读时的显示)。

## 和 disabled 的区别

- `disabled` 仍然显示输入控件，只是不能操作。
- `DouForm` 的 `readonly` 保留输入控件、只是不能修改，见[表单的只读](/components/form#只读)。
- 渲染器的 `readonly` 把控件整个换成文字。
