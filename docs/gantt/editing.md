# 编辑

不设置 `readonly` 时，甘特图可以直接拖动编辑，也可以在表格里修改，改动通过 `v-model` 写回。

## 拖动

<DocDemo src="gantt/editing" column />

- 拖动任务条改动起止时间，工期（工作日或工作小时）不变，跨过休息日时任务条相应变长。选中多个任务时一起移动，拖动汇总任务会移动它的全部子任务。
- 拖动任务条两端调整开始或结束时间，拖动底部的圆点调整进度。
- 从任务条两侧的连接点拖到另一个任务条上，新建一条依赖。落在目标任务条的左半边连到它的开始，右半边连到它的结束，由此决定依赖类型。
- 在未排期任务那一行的时间轴上拖动，为它画出起止时间。
- 点击依赖线选中它，按 `Delete` 删除。

拖动时显示新的起止时间和工期，表格同步更新，松开后才写回；拖动中按 `Escape` 取消。拖到时间轴边缘时会自动滚动。

只精确到日期的任务按整天对齐。精确到分钟的任务按缩放程度对齐：日刻度下按整天，小时刻度下按 1 小时、30 分钟或 15 分钟。

触屏上按住任务条片刻再拖动，直接滑动则是滚动时间轴；上下滑到时间轴的尽头后，页面接着滚动。

`locked: true` 的任务不能拖动。`readonly` 关闭界面上的全部编辑，代码调用 `transact` 仍然生效。

## 在表格里编辑

双击单元格可以直接修改，`Enter` 确认，`Esc` 取消，点到别处也会确认。键盘焦点在任务上时按 `F2` 修改任务名。

- 任务名、开始、结束、工期和进度都能改。
- 改开始时间会整体移动任务，工期不变。
- 改工期按工作日（精确到分钟的任务按工作小时）重新算结束时间。
- 汇总任务的时间和进度由子任务算出，不能直接改。

输入的值无法识别时（例如工期填了文字），输入框会保留并标红，读屏会提示未修改。

## 添加任务

表格最下面一行用来添加任务，输入名称后按 `Enter`，可以连续添加。新任务接在最后一个有日期的任务后面，占一个工作日，之后可以拖动或修改时间。不需要这一行时设 `:add-row="false"`。

通过 ref 调用 `insertTask(near, { where?, start? })` 在某个任务之后（或里面）添加一个任务并开始编辑名称，返回新任务的 id。

## 调整顺序和层级

拖动表格的行可以调整顺序：落在两行之间时插到那里，落在一行的中间时成为它的子任务。触屏上按住片刻再拖动。

`Ctrl` / `⌘` + `]` 把任务变成上一个任务的子任务，`Ctrl` / `⌘` + `[` 移出上级；修改任务名时按 `Tab`、`Shift` + `Tab` 也可以。通过 ref 可以调用 `indentTask(id)`、`outdentTask(id)`。

调整顺序只改被移动任务的 `parent` 和 `order`。`order` 是比较字符串大小的排序键，`orderBetween(a, b)` 可以生成两个键之间的新键，在服务端插入任务时也能用。

## 撤销与重做

每次拖动是一步，`Ctrl` / `⌘` + `Z` 撤销，`Ctrl` / `⌘` + `Shift` + `Z` 或 `Ctrl` + `Y` 重做，焦点需要在甘特图内。也可以通过 ref 调用 `undo()`、`redo()`，用 `canUndo`、`canRedo` 控制按钮状态。

展开、收起汇总任务不进入撤销记录。

## 依赖的限制

新建依赖时会拒绝这些情况：

- 连到自己；
- 连到自己的上级或子任务；
- 两个任务之间已经有依赖；
- 会形成循环依赖。

拖到这样的任务条上时，任务条显示为不可连接，并提示原因。

`canLink` 可以加上自己的限制：返回 `true` 允许，返回字符串则拒绝并把它作为提示。其他返回值都会拒绝，注意最后要 `return true`，漏写时开发环境下会提示。上面的示例里，已完成的任务不能再加前置任务。

## 移动的限制

`canMove` 在写入新的起止时间之前检查，拖动和键盘操作都会经过它。参数里的 `start`、`end` 是将要写入的值，写法和任务原来的一样：

```ts
const canMove = ({ start }: GanttMove) => start >= today || '不能排在今天之前'
```

返回 `true` 允许，返回字符串则拒绝并作为提示，其他返回值按“不能移到这里”拒绝。拖动时被拒绝的任务条显示为红色边框，松开后不会写入。

## API

### 相关 Props

| 名称       | 说明                                                                                       | 类型                                                                                         | 默认值  |
| ---------- | ------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------- | ------- |
| `readonly` | 只读：不能拖动、连线和在表格里编辑，撤销重做的快捷键也不响应；代码调用 `transact` 仍然生效 | `boolean`                                                                                    | `false` |
| `addRow`   | 可编辑时在表格最下方显示添加任务的一行                                                     | `boolean`                                                                                    | `true`  |
| `canLink`  | 连依赖前的最后一道检查，返回 `true` 允许，返回字符串时拒绝                                 | `(link: Pick<GanttLink, 'from' \| 'to' \| 'type'>, doc: GanttDocument) => boolean \| string` | —       |
| `canMove`  | 写入新的时间前的最后一道检查                                                               | `(move: GanttMove, doc: GanttDocument) => boolean \| string`                                 | —       |

### GanttMove

| 名称    | 说明                                         | 类型                  |
| ------- | -------------------------------------------- | --------------------- |
| `task`  | 要移动的任务                                 | `GanttTask`           |
| `start` | 将要写入的开始时间                           | `string`              |
| `end`   | 将要写入的结束时间，没有结束时间的里程碑不带 | `string \| undefined` |

### 相关 Exposes

| 名称                         | 说明                                                            | 类型                                                             |
| ---------------------------- | --------------------------------------------------------------- | ---------------------------------------------------------------- |
| `undo` / `redo`              | 撤销、重做                                                      | `() => boolean`                                                  |
| `canUndo` / `canRedo`        | 能否撤销、重做                                                  | `boolean`                                                        |
| `insertTask`                 | 在某个任务之后（或里面）添加一个任务并开始编辑名称，返回它的 id | `(near: string \| null, options?: GanttInsertOptions) => string` |
| `indentTask` / `outdentTask` | 缩进、取消缩进                                                  | `(id: string) => boolean`                                        |
| `editCell`                   | 开始编辑表格的单元格，默认名称；不能编辑时返回 `false`          | `(id: string, key?: string) => boolean`                          |

`insertTask` 的 `options`：`where` 是 `'after'`（默认）或 `'inside'`；`start` 是开始时间，日期或分钟数，不写时接在上一个任务后面，或从今天开始。
