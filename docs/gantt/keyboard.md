# 键盘操作

甘特图获得焦点后可以只用键盘操作，读屏软件会播报当前任务和每次修改的结果。

## 按键

| 按键                                       | 作用                                                                 |
| ------------------------------------------ | -------------------------------------------------------------------- |
| `↑` / `↓`、`Home` / `End`                  | 选择上一个、下一个、第一个、最后一个任务                             |
| `←` / `→`                                  | 收起、展开汇总任务；在子任务上按 `←` 回到上级                        |
| `Space`                                    | 加选或取消选中当前任务                                               |
| `Enter`                                    | 只选中当前任务                                                       |
| `Alt` + `←` / `→`                          | 把任务（或选中的全部任务）提前、推后一格，工期不变                   |
| `Alt` + `Shift` + `←` / `→`                | 提前、推后结束时间一格                                               |
| `L`                                        | 从当前任务添加依赖：`↑` / `↓` 选择后续任务，`Enter` 确认，`Esc` 取消 |
| `Delete`                                   | 删除选中的依赖线；没有选中依赖线时删除选中的任务                     |
| `F2`                                       | 修改任务名                                                           |
| `Ctrl` / `⌘` + `]` / `[`                   | 缩进、取消缩进                                                       |
| 菜单键、`Shift` + `F10`                    | 打开当前任务的[菜单](./menu)                                         |
| `Ctrl` / `⌘` + `Z`                         | 撤销                                                                 |
| `Ctrl` / `⌘` + `Shift` + `Z`、`Ctrl` + `Y` | 重做                                                                 |

一格的大小和拖动对齐的单位相同。连续按 `Alt` + 方向键移动同一个任务，撤销时作为一步。

## 焦点

`focusTask(id)` 把键盘焦点放到指定任务上，并滚动到它。`ariaLabel` 设置甘特图的无障碍名称。

扩展可以加自己的快捷键，见[扩展 · 快捷键](./extensions#快捷键)。
