# 国际化

DouUI 组件自己显示的文字，以及日期、数字的写法，都来自语言包。内置三个语言包：`zhCN`（简体中文，默认）、`zhTW`（繁体中文）与 `en`（英文）。

## 切换语言

用 [ConfigProvider](../components/config-provider) 包住应用或某个区域：

```vue
<script setup>
import { en } from 'dou-ui'
</script>

<template>
  <DouConfigProvider :locale="en">
    <App />
  </DouConfigProvider>
</template>
```

也可以在注册插件时传入：

```ts
import DouUI, { en } from 'dou-ui'

app.use(DouUI, { locale: en })
```

`locale` 是响应式的，换成另一个语言包，界面会立即更新。

## 语言包里有什么

语言包是一个普通对象，类型为 `Locale`，分为三部分：

- `name`：BCP 47 语言标签，如 `zh-CN`。星期、月份的名称由浏览器的 `Intl` 按它生成，不需要另外翻译。
- `region`：日期与数字的写法，见下文。
- 其余按组件分组的文案：按钮文字、读屏标签、表单的默认错误信息等，例如 `datePicker.today`、`form.required`。文案中的 `{min}` 这样的占位符会在使用时替换。

## 地区约定

`region` 决定和地区有关的默认值。组件上对应的属性始终优先。

| 字段                       | 作用                                           | `zhCN`          | `zhTW`          | `en`            |
| -------------------------- | ---------------------------------------------- | --------------- | --------------- | --------------- |
| `weekStart`                | 每周的第一天，`0` 周日、`1` 周一               | `1`             | `0`             | `0`             |
| `date` / `month` / `year`  | 日期、月份、年份的显示与输入格式               | `YYYY-MM-DD` 等 | `YYYY/MM/DD` 等 | `MM/DD/YYYY` 等 |
| `time` / `timeWithSeconds` | 时间的显示与输入格式，`hh` 与 `A` 为 12 小时制 | `HH:mm`         | `HH:mm`         | `hh:mm A`       |
| `groupSeparator`           | 千分位分隔符                                   | `,`             | `,`             | `,`             |
| `decimalSeparator`         | 小数点                                         | `.`             | `.`             | `.`             |

用到这些值的组件：

- `weekStart`：DatePicker、Calendar、InputDate 的日历，CalendarView。
- 日期与时间格式：DatePicker 输入框，InputDate、InputTime 的各段。格式只影响显示和输入，`v-model` 的值始终是 `YYYY-MM-DD`、`HH:mm` 这样的固定形式。
- 数字分隔符：Statistic。

## 自定义语言包

在内置语言包上改需要的部分即可。下面是一个按德国习惯写日期和数字的中文语言包：

```ts
import { zhCN } from 'dou-ui'
import type { Locale } from 'dou-ui'

const locale: Locale = {
  ...zhCN,
  region: {
    ...zhCN.region,
    date: 'DD.MM.YYYY',
    month: 'MM.YYYY',
    groupSeparator: '.',
    decimalSeparator: ',',
  },
  form: { ...zhCN.form, required: '必填' },
}
```

翻译成新的语言时，以 `en` 为底稿复制一份，逐项翻译，`Locale` 类型会检查有没有漏掉的条目。

## 和应用自己的国际化方案配合

DouUI 不读取应用的国际化库，只需要把当前语言对应的语言包交给 `ConfigProvider`。以 vue-i18n 为例：

```vue
<script setup>
import { computed } from 'vue'
import { useI18n } from 'vue-i18n'
import { en, zhCN, zhTW } from 'dou-ui'

const { locale } = useI18n()
const douLocale = computed(() => {
  if (/^zh-(TW|HK|MO|Hant)/i.test(locale.value)) return zhTW
  return locale.value.startsWith('zh') ? zhCN : en
})
</script>

<template>
  <DouConfigProvider :locale="douLocale">
    <RouterView />
  </DouConfigProvider>
</template>
```

## 在自己的组件中读取

`useLocale()` 返回当前的语言包和读取文案的函数：

```ts
import { useLocale } from 'dou-ui'

const { locale, t } = useLocale()
t('form.required') // '此项为必填项'
locale.value.region.weekStart // 1
```
