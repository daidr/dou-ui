# 浮层

提示、气泡卡片、下拉菜单、对话框与抽屉都画在页面之上。它们共用同一套基础设施，所以行为一致：怎么定位、谁在上面、按 `Esc` 关哪一个、焦点去哪儿。这一页说明这些共同的约定，各组件的文档只写自己特有的部分。

## 渲染位置

浮层默认通过 `Teleport` 渲染到 `<body>` 末尾，不会被祖先的 `overflow: hidden` 裁掉，也不受祖先 `z-index` 的层叠上下文限制。第一次打开时才渲染，之后保留（对话框与抽屉可以用 `destroy-on-close` 在关闭后卸载内容）。

所有浮层组件都有 `teleport` 属性：传入选择器或元素可以换一个容器，传 `false` 则原地渲染。

离开原来的子树会丢掉写在祖先上的 `data-dou-theme`，因此浮层打开时会读取声明处生效的主题，并写回到自己身上——局部的深色区域里弹出的菜单也是深色的。

## 定位

锚定在触发元素上的浮层（提示、气泡卡片、下拉菜单）使用 `position: fixed`，按 `placement` 放在触发元素的一侧：`top`、`right`、`bottom`、`left`，可加 `-start` / `-end` 与触发元素的一端对齐。

- **翻转**：首选的一侧放不下、而对侧空间更大时，换到对侧。
- **贴边**：沿另一条轴滑动，与视口边缘至少保持 8px。
- **跟随**：打开期间，页面滚动、窗口缩放、触发元素或浮层尺寸变化时都会重新计算。

进出场动画从贴着触发元素的那一角展开，并朝它偏移 4px。

## 层级

每打开一个浮层，都从 [全局配置](../components/config-provider) 的 `zIndex`（默认 `2000`）起取一个更高的层级，后打开的总在上面——对话框里的下拉菜单不会被对话框盖住。

## 关闭

打开的浮层组成一个栈：

- **`Esc`** 只交给最上面的一个。即便它选择不关闭（例如 `close-on-escape` 为 `false` 的对话框），也不会传到下面的浮层。
- **点击外部**：按下的位置既不在浮层与它的触发元素里、也不在从它内部打开的浮层里，才算"外部"。所以在对话框里打开下拉菜单再点菜单项，不会关掉对话框。

## 焦点

- **提示** 不改变焦点。
- **气泡卡片** 是非模态的：焦点留在触发元素上，`Tab` 进入卡片，从卡片两端 `Tab` 出去会回到触发元素，再按浏览器原本的顺序继续。
- **下拉菜单** 用键盘打开时聚焦第一项，方向键在项之间移动；选中、`Esc` 或 `Tab` 关闭后，焦点回到触发元素。
- **对话框与抽屉** 是模态的：打开时焦点移入面板（有 `autofocus` 的元素优先，否则是面板本身，读屏会先读出标题），`Tab` 在面板内循环，关闭后焦点回到打开前的位置。打开期间页面滚动被锁定，并补上滚动条的宽度，背后的内容不会跳动。
