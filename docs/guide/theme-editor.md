# 主题编辑器

调整下面的选项，预览区域会实时套用生成的主题，下方给出对应的代码。生成方式见 [主题与 Token](./theming#从品牌色生成)。

<DocThemeEditor />

说明：

- 颜色由 `createTheme` 处理，每个颜色会生成 `DEFAULT`、`on`、`text` 三个值，亮色和暗色主题分别保证文字对比度不低于 4.5:1。没有修改的颜色不会出现在代码里。
- 中性色倾向会给背景、文字和边框的灰色加上很少的色度，明度不变。
- 圆角调整的是 `radius.control`，`radius.container` 随之变化（控件圆角加 6px）。
- 字号调整的是 `font.size.md`，`sm` 和 `lg` 分别比它小 1px、大 2px。
- 预览区域可以单独切换亮色和暗色，不影响页面本身。

生成的 `css` 是一段普通的 CSS 文本，可以在构建时写入样式文件，也可以在运行时插入 `<style>` 标签。
