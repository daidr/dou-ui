# 视觉语言

DouUI 的整体风格是**简洁、克制**：界面以接近黑色、白色和少量灰色为主，
颜色只用来表达含义，并且都是低饱和度的。

## 原则

### 以中性色为主

默认使用中性色：主按钮在浅色主题下是近黑色，在深色主题下是近白色，而不是品牌蓝。
只有需要表达“主要操作 / 成功 / 警告 / 危险”时，才使用对应的语气色。
同一屏中彩色元素越少，每个彩色元素就越醒目。

### 用灰阶和细线区分层级

区分层级的方式按优先级排列：

1. **文字灰阶**：`text` → `text-secondary` → `text-tertiary`
2. **表面**：`bg-canvas`（页面）上放 `bg-surface`（卡片、输入框）
3. **1px 细线**：`border-subtle` 分隔区域，`border` 勾勒控件，`border-strong` 用于悬停与强调
4. **阴影**：最后才考虑，颜色很淡，只用于浮在页面上方的元素

### 低饱和的语气色

语气色都偏灰，避免过于鲜艳：

<TokenSwatches group="tone" />

每个色块左半是浅色主题，右半是深色主题。深色主题下语气色更亮、更柔和，
实心按钮上的文字也随之变为深色。

### 边框与阴影

纯色块容易显得单薄，因此除 ghost 外，每种控件样式都带有清晰的边框：

- **solid**：描边比填充色深一档（与 `--dou-color-edge` 混合），顶部一道极淡的内高光（`--dou-shadow-highlight`），
  下方是带一点自身色调的柔和投影，让按钮有实体按键的立体感。
- **soft**：浅色调底 + 同色调细描边 + 静止阴影。
- **outline**：白底 + 中性细描边 + 静止阴影，悬停时描边加深。
- **ghost**：没有边框和阴影，悬停时才显示底色，用于最次要的操作。

按下时投影消失，只保留内高光，并下移 0.5px，模拟按键被按下。

### 交互反馈

- 悬停：实心按钮向页面底色方向**变浅**一点，其余样式显示很淡的语气色底，描边加深。
- 按下：底色再加深一些，投影消失，并下移 0.5px。
- 焦点：只在键盘操作时出现的 2px 柔和蓝色描边，与元素留 2px 间隙。
- 动效：时长从 150ms 起，缓动平滑，没有回弹；遵循系统的“减少动态效果”设置。

## 字体

使用系统字体栈，在各个平台上显示清晰，并且不需要额外加载字体。
等宽字体用于代码、哈希、版本号等内容。

| Token                 | 值              | 用途                     |
| --------------------- | --------------- | ------------------------ |
| `--dou-font-size-sm`  | 13px            | 辅助信息、紧凑控件       |
| `--dou-font-size-md`  | 14px            | 正文与大多数控件         |
| `--dou-font-size-lg`  | 16px            | 标题、大号控件           |
| `--dou-font-weight-*` | 400 / 500 / 600 | 正文 / 控件与强调 / 标题 |

字重最高为 600，不使用更粗的字重来区分层级。

### 垂直居中

字体自带的上下留白（ascent / descent）因平台而异，中文又常由回退字体绘制，按行盒居中时文字容易偏上或偏下。
控件里的单行文字（按钮、标签、多选框 / 单选框 / 开关的文字、分割线文字）使用
`text-box: trim-both cap alphabetic`，按"大写字母顶端到基线"这段区域居中，与字体的留白无关。
不支持该属性的浏览器会退回到按行盒居中。输入框内的文字由浏览器绘制，暂不处理。

## 形状与尺寸

| Token                       | 值             | 说明                 |
| --------------------------- | -------------- | -------------------- |
| `--dou-radius-control`      | 6px            | 按钮、输入框等控件   |
| `--dou-radius-container`    | 12px           | 卡片、对话框等容器   |
| `--dou-control-height-*`    | 28 / 32 / 40px | 同一行的控件高度对齐 |
| `--dou-control-padding-x-*` | 10 / 12 / 16px |                      |
| `--dou-space-*`             | 8 / 12 / 20px  | 相邻元素之间的间距   |

圆角保持小而统一：控件 6px、容器 12px，容器的圆角大于其中的控件。

## 阴影

| Token             | 用途                       |
| ----------------- | -------------------------- |
| `--dou-shadow-sm` | 静止的描边控件，几乎不可见 |
| `--dou-shadow-md` | 卡片、下拉菜单             |
| `--dou-shadow-lg` | 对话框等覆盖层             |

深色主题下阴影几乎不可见，层级主要依靠表面色和细线区分。
