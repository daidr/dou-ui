# 图标库

`dou-icons` 是与 DouUI 同一套视觉语言绘制的线性图标库：16 × 16 网格、1.5 线宽、圆头圆角、颜色跟随文字。它是独立的子包，不依赖 `dou-ui`，任何 Vue 3 项目都能用。目前共 {{ icons.length }} 个图标，会按需要逐步补充。

点击图标查看详情、复制引入代码或 SVG 源码。用法见 [安装与使用](./usage)，绘制规则见 [绘制规范](./design)。
