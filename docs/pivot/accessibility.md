# 无障碍

透视表可以只用键盘操作，读屏能读出表格的结构和选中的格子。

## 键盘

表格可以聚焦，方向键移动选中的格子。

| 按键                            | 作用                                      |
| ------------------------------- | ----------------------------------------- |
| 方向键                          | 移动选中的格子                            |
| → / ←（在组名上）               | 展开 / 折叠，或回到上一级                 |
| Enter / 空格（在组名上）        | 切换展开                                  |
| Enter（在数字上）               | 触发 `cellClick`，见[查看明细](./details) |
| Page Up / Page Down             | 翻页                                      |
| Home / End                      | 跳到行首、行尾                            |
| Ctrl / ⌘ + Home、Ctrl / ⌘ + End | 跳到第一行、最后一行                      |
| Shift + 以上移动键              | 扩大选中的范围                            |
| Ctrl / ⌘ + A                    | 全选                                      |
| Ctrl / ⌘ + C                    | [复制](./export#选择与复制)               |
| Esc                             | 取消选中的范围                            |

## 读屏

- 表格是一个树形网格（`role="treegrid"`），每行带有层级（`aria-level`），组所在的行带有展开状态（`aria-expanded`），排序中的表头带有 `aria-sort`。
- 表格可以多选（`aria-multiselectable`），选中范围内的格子带有 `aria-selected`。用方向键移动时，读屏读出选中的格子。
- 选中一片格子、复制、展开或折叠一组时，表格通过一个隐藏的 `role="status"` 区域播报结果，比如“已选中 3 行 2 列”“已复制 6 个格子”。

`ariaLabel` 设置表格的名称，默认是“数据透视表”。
