# 字段面板

`DouPivotFields` 是配套的字段面板，用来在界面里调整字段放在哪里。

## 基础用法

面板和表格绑定同一个 `config`，`data` 和 `fields` 也传同一份：

<DocDemo src="pivot/fields" />

面板上方列出所有字段，可以搜索；下方是筛选、列、行、值四个区域：

- 把字段拖进区域、在区域里拖动调整顺序、拖回列表移除；
- 勾选字段前的复选框会把它加到合适的位置，数值字段加到值，其他字段加到行。

## 字段菜单

区域里的每个字段右侧有两个按钮：

- 漏斗按钮打开筛选，勾选要保留的组；
- 箭头按钮打开菜单，可以调整排序、分组、小计、汇总方式、显示方式和条件格式，上移、下移，或者移到其他区域。

行和列上字段的菜单里有“前 N 项”，选“自定义…”可以填任意项数，或者按合计范围筛选，见[筛选](./grouping#筛选)。值区域的“添加计算值”可以写[公式](./formula)。传给面板的 `aggregators` 会出现在值的汇总方式里。

## 手机上

按住字段片刻再拖动，直接滑动用来滚动面板。`drawer` 为 `'auto'`（默认）时，屏幕窄于 `sm` 断点时面板收成一个按钮，点击后从底部打开；设为 `true` 或 `false` 可以固定其中一种。

## API

### PivotFields Props

| 名称          | 说明                                            | 类型                       | 默认值         |
| ------------- | ----------------------------------------------- | -------------------------- | -------------- |
| `data`        | 记录，和表格传同一份                            | `object[] \| PivotColumns` | —              |
| `fields`      | 字段的说明，和表格传同一份                      | `PivotField[]`             | 从记录的键推断 |
| `config`      | 字段放在哪里，支持 `v-model:config`             | `PivotConfig`              | `{}`           |
| `aggregators` | 自定义的汇总方式，会出现在值的菜单里            | `PivotAggregator[]`        | —              |
| `drawer`      | 是否收成按钮、从底部打开；`'auto'` 在窄屏上收起 | `boolean \| 'auto'`        | `'auto'`       |
| `messages`    | 替换语言包里的文字                              | `PivotMessagesOverride`    | —              |

### PivotFields Events

| 名称            | 说明             | 参数          |
| --------------- | ---------------- | ------------- |
| `update:config` | 调整字段的位置时 | `PivotConfig` |
