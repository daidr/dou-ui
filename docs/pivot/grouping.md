# 分组、排序与筛选

行和列上的字段默认按每个不同的值分组，按组名排序。这一页介绍按区间分组、调整顺序和只保留一部分组。

下面的例子按季度或月份给下单日期分组，打开开关后只保留销售额最高的两个地区。点击值的表头可以按数值排序。

## 分组

日期和数字字段可以按区间分组。在行或列上写成对象，用 `by` 指定分组方式：

```ts
const config = {
  rows: [{ field: 'date', by: 'month' }],
  columns: [{ field: 'amount', by: { step: 100 } }],
}
```

- 日期可以按 `'year'`、`'quarter'`、`'month'`、`'week'`、`'day'` 分组，周按 ISO 周计算，从周一开始。
- 数字按 `{ step, start? }` 分成等宽的区间，`start` 默认是 `0`。

组名是可以保存的普通数据：

| 分组方式           | 组名                    |
| ------------------ | ----------------------- |
| `'year'`           | 数字，如 `2026`         |
| `'quarter'`        | 文字，如 `'2026-Q1'`    |
| `'month'`          | 文字，如 `'2026-03'`    |
| `'week'`           | 文字，如 `'2026-W12'`   |
| `'day'`            | 文字，如 `'2026-03-15'` |
| `{ step, start? }` | 区间的下限，如 `100`    |

`filters`、`collapsed` 和 `cellClick` 的 `row`、`column` 里都用这些组名。表格里显示的是“2026 年 Q1”这样的文字。

## 排序

行上的组默认按组名升序排列：中文按拼音，数字按大小，字段的 `order` 优先。点击左上角的字段名切换这一级的升序和降序，也可以在 `rows` 里写 `{ field: 'city', sort: 'desc' }`。

点击值的表头按这一列的数值排序：第一次从大到小，第二次从小到大，第三次恢复按组名排序。每一级的组在各自的上一级里排序。按数值排序记录在 `config.sort` 里：

```ts
sort: { valueIndex: 0, column: ['Q4'], order: 'desc' } // 按 Q4 那一列的第 1 个值降序
```

`valueIndex` 是值在 `values` 里的序号，`column` 是列组的组名，`[]` 表示总计列。

## 小计

行或列上的某个字段不需要小计时，写成 `{ field: 'city', subtotal: false }`：行上展开的组不再显示数字，列上的组后面不再有“合计”列。

## 筛选

`filters` 按字段保留或排除一些组，排除的记录不参与任何汇总：

```ts
filters: {
  channel: { exclude: ['外卖'] },
  region: { include: ['华东', '华南'] },
}
```

筛选的字段不必放在行或列上，放在字段面板的“筛选”区域即可。没有记录通过筛选时，表格中间显示“没有数据”。

### 按合计筛选

`top` 按合计保留最大（或最小）的几组，`between` 保留合计在某个范围里的组：

```ts
filters: {
  city: { top: { count: 10 } }, // 销售额最高的 10 个城市
  category: { top: { count: 3, valueIndex: 1, order: 'asc' } }, // 按第 2 个值，最小的 3 个
  region: { between: { min: 10000 } },
}
```

合计按 `values` 里第 `valueIndex` 个值（默认第一个）计算，统计的是经过 `include` / `exclude` 筛选后的记录。被排除的组不计入总计。

### 筛选分组后的字段

筛选里的组名按这个字段在行或列上的分组来认，例如按月分组时写 `{ include: ['2026-03'] }`。

字段不在行列上、只放在筛选区域时，在筛选里写上 `by`，例如 `{ include: ['2026-Q1'], by: 'quarter' }`。在字段面板里改变分组时，这个字段的筛选会被清空。

## API

### PivotDimension

`rows` 和 `columns` 里的每一项可以是字段名，也可以是这样一个对象：

| 名称       | 说明                       | 类型                                                                    | 默认值  |
| ---------- | -------------------------- | ----------------------------------------------------------------------- | ------- |
| `field`    | 字段名                     | `string`                                                                | —       |
| `sort`     | 按组名排序的方向           | `'asc' \| 'desc'`                                                       | `'asc'` |
| `subtotal` | 是否显示这个字段各组的小计 | `boolean`                                                               | `true`  |
| `by`       | 按区间分组                 | `'year' \| 'quarter' \| 'month' \| 'week' \| 'day' \| { step, start? }` | —       |

### PivotFilter

| 名称      | 说明                                              | 类型                             |
| --------- | ------------------------------------------------- | -------------------------------- |
| `include` | 只保留这些组                                      | `unknown[]`                      |
| `exclude` | 排除这些组                                        | `unknown[]`                      |
| `top`     | 按合计保留最大或最小的几组，`order` 默认 `'desc'` | `{ count, valueIndex?, order? }` |
| `between` | 保留合计在范围里的组                              | `{ min?, max?, valueIndex? }`    |
| `by`      | 上面的组名按哪种分组来认；不写时用行列上的分组    | `PivotGroupBy`                   |

### PivotValueSort

| 名称         | 说明                     | 类型              | 默认值 |
| ------------ | ------------------------ | ----------------- | ------ |
| `valueIndex` | 值在 `values` 里的序号   | `number`          | —      |
| `column`     | 按哪一列排序，列组的组名 | `unknown[]`       | `[]`   |
| `order`      | 方向                     | `'asc' \| 'desc'` | —      |
