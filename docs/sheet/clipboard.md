# 复制、粘贴与填充

复制粘贴可以和其他表格软件、文档、网页互通，填充柄按选区的内容推算后面的值。

## 复制与粘贴

`Ctrl` / `⌘` + `C` 复制，`Ctrl` / `⌘` + `X` 剪切，`Ctrl` / `⌘` + `V` 粘贴，也可以用右键菜单。复制的区域显示虚线框，按 `Esc` 取消。

复制时剪贴板里同时放入两种内容：用制表符分隔的纯文本（按单元格显示的文字），以及带简单格式的表格。所以：

- 复制到其他表格软件、文档或网页时保留行列。
- 从其他地方复制过来的表格和制表符分隔的文字，每个单元格按[输入的规则](./editing#输入的识别)读成值，比如 `12%` 读成 `0.12` 并加上百分比格式。目标单元格原来的样式保留。
- 从这张表或另一个 `DouSheet` 复制的内容原样粘贴，包括格式、样式和批注。

粘贴的位置：

- 复制一个单元格，粘贴时填满整个选区。
- 选区正好是复制内容的整数倍时，重复填满选区；否则从选区左上角开始粘贴，并选中粘贴的区域。
- 复制的公式粘贴后，没有 `$` 的引用随位置移动，`=A1*2` 向下粘贴一行变成 `=A2*2`。
- 剪切后粘贴是移动：原位置被清空，移动的公式保持不变，其他公式里指向这些单元格的引用改成新的位置；指向被覆盖的单元格的引用变成 `#REF!`。

右键菜单里的复制、粘贴使用浏览器的剪贴板接口，第一次粘贴时浏览器可能会询问权限；不允许读取剪贴板时，表格会提示改用快捷键。

## 粘贴事件

写入之前触发 `paste` 事件。`event.clip.cells` 是要粘贴的单元格，`event.range` 是粘贴的位置。可以修改或替换 `event.clip`，也可以调用 `event.preventDefault()` 取消粘贴：

```vue
<DouSheet v-model="book" @paste="onPaste" />
```

```ts
import type { SheetPasteEvent } from '@dou-ui/sheet'

function onPaste(event: SheetPasteEvent) {
  // 去掉粘贴进来的文字首尾的空格
  event.clip = {
    ...event.clip,
    cells: event.clip.cells.map((row) =>
      row.map((cell) => (typeof cell === 'string' ? cell.trim() : cell)),
    ),
  }
}
```

要在几个表格里复用同样的处理，用扩展的 `transformPaste`，见[扩展](./extensions#改写粘贴的内容)。

## 用代码复制粘贴

- 组件实例的 `copy()`、`cut()`、`paste(clip?)` 和快捷键做同样的事。`paste` 也可以直接传入 `parseClip` 读出的内容。
- `formatClip(clip, { locale, text, result })` 把单元格转成剪贴板里的文字和表格，`text` 可以给出某个单元格的文字，`result` 给出公式的结果（见[在表格之外读取结果](./formulas#在表格之外读取结果)），不给时写公式本身。带类型的单元格使用类型的 `format`。

## 填充

选区右下角的小方块是填充柄，拖动它把选区延伸到相邻的单元格。

<DocDemo src="sheet/fill" column />

填充柄按选区里的内容推算后面的值：

| 选区内容                            | 拖出的值                               |
| ----------------------------------- | -------------------------------------- |
| 一个数字 `5`                        | 复制：`5, 5, 5`                        |
| 等差的数字 `1, 3`                   | 继续：`5, 7, 9`；不等差时按趋势线推算  |
| 日期 `2026-10-30`                   | 每次加一天                             |
| 每月同一天 `2026-01-15, 2026-02-15` | 每次加一个月                           |
| 月末 `2026-01-31, 2026-02-28`       | 每月最后一天：`2026-03-31, 2026-04-30` |
| 时间 `9:00`、`9:00, 9:30`           | 每次加一小时，或按间隔继续             |
| 带数字的文字 `第 1 周`              | `第 2 周, 第 3 周`                     |
| 其他文字、公式                      | 依次重复，公式的引用随位置移动         |

- 向上、向左拖时反向推算。拖动时旁边显示最后一格将要填入的值。
- 按住 `Ctrl` / `⌘`（或 `Alt`）拖动时做相反的事：会继续的内容改为复制，一个数字改为逐个加一。
- 把填充柄拖回选区内会清空经过的单元格。
- 双击填充柄，向下填充到左右相邻一列数据的末尾。
- 触屏上填充柄显示为圆点，按住直接拖动即可，不需要长按。

`Ctrl` / `⌘` + `D` 用选区第一行向下填充，`Ctrl` / `⌘` + `R` 用第一列向右填充，都是直接复制；只选了一行时复制上面一行。

代码里用 `continueValues(values, count, { mode })` 得到填充柄会给出的值，`fillContinues(values)` 判断默认是继续还是复制。

## API

### SheetPasteEvent

| 属性               | 说明                   | 类型         |
| ------------------ | ---------------------- | ------------ |
| `clip`             | 要粘贴的内容，可以替换 | `SheetClip`  |
| `range`            | 粘贴的位置             | `SheetRange` |
| `preventDefault()` | 取消粘贴               | `() => void` |
| `defaultPrevented` | 是否已取消             | `boolean`    |

### SheetClip

| 属性     | 说明                                             | 类型                           |
| -------- | ------------------------------------------------ | ------------------------------ |
| `cells`  | 按行排列的单元格                                 | `SheetCellInput[][]`           |
| `styles` | 单元格用到的命名样式                             | `Record<string, SheetStyle>`   |
| `from`   | 从表格里复制时，复制的左上角，粘贴时公式据此移动 | `{ row: number, col: number }` |
| `cut`    | 剪切时才有，粘贴时移动单元格                     | `string`                       |
