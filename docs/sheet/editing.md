# 选择与编辑

在表格里选择区域、输入内容、撤销修改，以及可用的快捷键。

## 选择

点击选中一个单元格，拖动选中一片区域。

<DocDemo src="sheet/selection" column />

- 按住 `Shift` 点击扩大当前区域，按住 `Ctrl` / `⌘` 点击再加一片区域。
- 点击列标或行号选中整列、整行，点击左上角全选。
- 拖到表格边缘时自动滚动。
- 触屏上单指滑动是滚动表格，轻点选中单元格；按住片刻后拖动选择区域。

`v-model:selection` 读写选区：`ranges` 是选中的区域，`active` 是键盘所在的单元格，总在最后一片区域里。坐标从 0 开始，`formatRange` 把区域转成 `A1:C4` 这样的名字，`parseRange` 反过来。选区的格式见[文档数据 · 选区](./data#选区)。

## 编辑

- 选中单元格后直接输入，替换它的内容；输入法也可以直接开始。
- 双击或按 `F2` 编辑原来的内容。触屏上再点一次选中的单元格开始编辑。
- `Enter` 确认并移到下一行，`Tab` 确认并移到右边一格，`Esc` 取消，点到别处也会确认。
- `Alt` + `Enter` 在单元格里换行。
- `Delete` 或 `Backspace` 清空选中区域的值，样式和格式不变。

直接输入开始的编辑里，方向键确认并移动，便于连续录入；按 `F2` 开始的编辑里，方向键移动光标。编辑中按 `F2` 在两种方式之间切换。

触屏上编辑框的字号至少是 16px，避免手机在聚焦时自动放大页面。

## 输入的识别

输入的内容按下面的规则读成值：

| 输入                                 | 写入的值                                     |
| ------------------------------------ | -------------------------------------------- |
| `1234`、`1,234.5`、`-3e2`            | 数字                                         |
| `12.5%`                              | `0.125`，没有格式时加上格式 `0.0%`           |
| `¥1,200`、`$12.50`、`-€3`            | 数字，加上货币格式 `¥#,##0`、`$#,##0.00`     |
| `2026-03-05`、`2026/3/5`、`2026.3.5` | 日期字符串 `'2026-03-05'`；可以带时间 `9:30` |
| `9:30`、`18:30:15`                   | 时间字符串 `'09:30'`、`'18:30:15'`           |
| `true`、`FALSE`                      | 布尔值                                       |
| `=SUM(A1:A3)`                        | 公式，显示计算结果，见[公式](./formulas)     |
| `'007`                               | 文字 `'007'`，开头的 `'` 表示按文字保存      |
| 其他                                 | 文字                                         |

日期和时间统一按 `'YYYY-MM-DD HH:mm'` 这样的写法保存。用其他写法输入时，会同时加上对应的格式，让单元格仍按输入的样子显示：

- 输入 `2026/3/5`，保存为 `'2026-03-05'`，格式为 `yyyy/m/d`。
- 输入 `9:30`，保存为 `'09:30'`，格式为 `h:mm`。
- 只有输入时带了前导 0 的部分才补零。`2026/12/5` 的格式是 `yyyy/m/d`，之后改成 1 月也显示为 `2026/1/5`。

单元格原来的样式和格式会保留，没有格式时才加上输入带来的格式。

## 撤销与重做

`Ctrl` / `⌘` + `Z` 撤销，`Ctrl` / `⌘` + `Shift` + `Z` 或 `Ctrl` + `Y` 重做，撤销后选区回到修改时的位置。

组件实例的 `undo()`、`redo()` 做同样的事，`canUndo`、`canRedo` 可以控制按钮状态。`historyDepth` 设置最多能撤销多少步，默认 100。`v-model` 被整个换成另一份数据时，撤销记录会清空。

## 快捷键

| 按键                                                     | 作用                                           |
| -------------------------------------------------------- | ---------------------------------------------- |
| 方向键                                                   | 移动一格，跳过隐藏的行和列                     |
| `Ctrl` / `⌘` + 方向键                                    | 移到数据区域的边缘，或下一个有内容的单元格     |
| `Shift` + 方向键                                         | 扩大选区；加上 `Ctrl` / `⌘` 一次扩到边缘       |
| `Enter` / `Tab`（加 `Shift` 反向）                       | 下移、右移；选中一片区域时在区域内循环         |
| `Home` / `End`                                           | 行首、本行最后一个有内容的单元格               |
| `Ctrl` / `⌘` + `Home` / `End`                            | `A1`、有内容的最后一格                         |
| `Page Up` / `Page Down`                                  | 翻一屏                                         |
| `Shift` + `Space`、`Ctrl` + `Space`                      | 选中整行、整列                                 |
| `Ctrl` / `⌘` + `A`                                       | 全选                                           |
| `F2`                                                     | 编辑                                           |
| `Shift` + `F2`                                           | 插入或编辑批注                                 |
| `Ctrl` / `⌘` + `K`                                       | 插入或编辑链接                                 |
| `Ctrl` / `⌘` + `Alt` + `M`                               | 打开或发起评论，见[评论](./comments)           |
| `Delete` / `Backspace`                                   | 清空选中区域的值                               |
| `Ctrl` / `⌘` + `C` / `X` / `V`                           | 复制、剪切、粘贴                               |
| `Ctrl` / `⌘` + `D` / `R`                                 | 向下、向右填充                                 |
| `Ctrl` / `⌘` + `B` / `I` / `U`                           | 加粗、斜体、下划线（按当前单元格切换）         |
| `Ctrl` / `⌘` + `Shift` + `X`                             | 删除线                                         |
| `Ctrl` / `⌘` + `\`                                       | 清除格式                                       |
| `Ctrl` / `⌘` + `Shift` + `=`                             | 选中整行（整列）时，在前面插入同样多的行（列） |
| `Ctrl` / `⌘` + `-`                                       | 选中整行（整列）时，删除它们                   |
| `Alt` + `Shift` + `→` / `←`                              | 分组、取消分组，见[分组](./rows#分组)          |
| 菜单键、`Shift` + `F10`                                  | 打开右键菜单                                   |
| `Ctrl` + `Page Up` / `Page Down`                         | 上一个、下一个工作表                           |
| `Ctrl` / `⌘` + `F`                                       | 查找，见[查找和替换](./filter#查找和替换)      |
| `Ctrl` + `H`（macOS 上是 `⌘` + `Option` + `F`）          | 替换                                           |
| `F3`、`Ctrl` / `⌘` + `G`（加 `Shift` 反向）              | 下一个、上一个查找结果                         |
| `Ctrl` + `Shift` + `L`（macOS 上是 `⌘` + `Shift` + `L`） | 加上或去掉筛选                                 |
| `Alt` + `↓`                                              | 展开下拉列表、日历或筛选面板                   |
| `Esc`                                                    | 取消复制的虚线框；关闭查找面板                 |

读屏软件会播报当前单元格、选区大小和每次修改的结果。

## API

### 函数

| 名称                        | 说明                                                                                            |
| --------------------------- | ----------------------------------------------------------------------------------------------- |
| `formatRange(range, size?)` | 把区域转成 `A1:C4` 这样的名字；传入工作表的 `{ rows, cols }` 时，整列写成 `B:B`、整行写成 `2:2` |
| `parseRange(text)`          | 把 `A1:C4`、`B:D`、`2:3` 这样的名字读成区域，读不了时返回 `null`                                |
| `boundsOf(range)`           | 区域排好顺序的 `top`、`left`、`bottom`、`right`                                                 |
