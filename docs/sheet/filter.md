# 筛选、排序与查找

按某一列排列行，筛选出要看的行，以及查找和替换单元格里的内容。

## 筛选

右键菜单的“筛选”，或 `Ctrl` + `Shift` + `L`（macOS 上是 `⌘` + `Shift` + `L`），给选中的区域加上筛选；只选中一个单元格时，使用它周围连成一片的单元格。再按一次取消筛选。

<DocDemo src="sheet/filter" column />

区域的第一行是表头，每个表头右侧有筛选按钮。点击按钮，或在表头上按 `Alt` + `↓`，打开筛选面板：

- 升序、降序：只排列筛选区域里的行，表头不动，按钮上显示排序方向。
- 按值：勾选要显示的值，可以搜索。列出的值只来自其他列筛选后留下的行。
- 按条件：等于、大于、包含、开头是、为空等。数字按大小比较，文字不区分大小写。

被筛掉的行只是不显示，数据和行高都不变，清除筛选后重新显示。筛选后修改单元格，不再符合条件的行会留在原处，直到下次改动筛选条件时才隐藏，避免正在编辑的行突然消失。

筛选保存在工作表的 `filter` 里，见[文档数据 · 筛选](./data#筛选)。

## 排序

右键菜单的“排序”按当前单元格所在的列排列行：

- 选中多行时，排列选中的行。
- 只选中一个单元格时，在筛选区域里就排列筛选区域，否则排列它周围连成一片的单元格；第一行都是文字时当作表头留在原处。

排序的规则：

- 数字排在文字前面，文字按当前语言的习惯排列（中文按拼音）。
- 空单元格不论升序降序都排在最后，值相同的行保持原来的顺序。
- 公式跟着所在的行移动，引用像复制时一样跟着移动。
- 含有合并单元格的区域不能排序。

## 查找和替换

按 `Ctrl` / `⌘` + `F` 打开查找面板，`Ctrl` + `H`（macOS 上是 `⌘` + `Option` + `F`）打开替换。

<DocDemo src="sheet/find" />

- 输入时选中当前单元格之后的第一个结果，`Enter` / `Shift` + `Enter` 在结果间前后移动，看得见的结果都标上底色。
- 面板停在表格右上角，挡住当前结果时移到右下角。
- 超过两万个单元格的表格，等输入停顿一下再查找，打字不会卡顿。
- 隐藏的行列、筛选掉的行、折叠的分组和被合并单元格盖住的单元格都不参与查找。

表格是虚拟滚动的，浏览器自带的查找只能找到画出来的那几十行，所以表格自己接管了这两个快捷键。触屏设备上用工具栏的 `find`、`replace` 按钮打开面板。

查找框里有四个开关：

- **区分大小写**。
- **单元格完全匹配**：单元格的全部文字等于查找的内容才算。
- **查找公式**：默认按单元格显示的文字查找，金额按格式写成 `¥1,280.00`，公式按算出的结果；打开后按输入的内容查找，公式按公式本身查找，比如找 `B2` 能找到引用了它的公式。
- **所有工作表**：默认只找当前工作表，打开后找整个工作簿，结果在别的表时切换过去。

## 替换的规则

替换改的是单元格里输入的内容，替换后的文字和手动输入一样重新识别成数字或日期，原来的数字格式保留。

按显示的文字查找时，查到的文字可能只在显示格式里，比如在显示为 `¥12.00`、实际输入 `12` 的单元格里查 `12.00`。这时在显示的文字上替换，再像手动输入一样识别：`12.00` 换成 `13.00` 得到 `13`，格式不变。识别出来不是同一类值的会跳过，比如把 `¥` 换成别的字。

下面几种也会跳过：

- 公式算出的结果。打开“查找公式”才能替换公式本身。
- 受保护工作表里锁定的单元格，见[保护](./protect)。
- 替换后不符合数据验证（拒绝输入的规则）的单元格。

全部替换作为一步撤销，事务的 `action` 是 `'replace'`。有跳过的单元格时，表格下方按原因分别提示数量。只读的表格只能查找。

## 用代码查找

- `openSearch({ search: '白板' })` 打开面板并填好查找内容，带上 `replace` 时同时打开替换框；`closeSearch()` 关闭面板。
- `findCells(query)` 只返回结果、不打开面板，按工作表、行、列的顺序返回 `{ sheet, row, col }` 列表，规则和面板相同。
- 查找和替换登记成了命令 `find`、`replace`、`find.next`、`find.previous`，用扩展替换 `find`、`replace` 命令，就能换成自己的查找界面，见[命令](./commands#内置命令)。

面板上的文字（查找、替换、上一个、结果数等）在 [ConfigProvider](../components/config-provider) 语言包的 `findReplace` 里；表格自己的开关和跳过的提示在组件 `messages` 的 `find` 里。

## 用代码排序和筛选

```ts
sheet.value.transact((tr) => {
  tr.sortRange('A1:G25', [{ col: 5, order: 'desc' }], { header: true })
  tr.setFilter('A1:G25')
  tr.filterColumn(1, { values: ['上海', '杭州'] })
  tr.filterColumn(3, { condition: { op: 'ge', value: 10 } })
})
```

`sortRange` 的 `valueAt(row, col)` 可以提供每个单元格用来比较的值。不提供时按单元格里写的值比较，公式按公式文字比较；表格里的排序按计算结果比较。

## API

### SheetSearchQuery

| 字段            | 说明                                         | 类型                     |
| --------------- | -------------------------------------------- | ------------------------ |
| `search`        | 查找的文字                                   | `string`                 |
| `replace`       | 替换成的文字                                 | `string`                 |
| `caseSensitive` | 区分大小写                                   | `boolean`                |
| `wholeCell`     | 单元格完全匹配                               | `boolean`                |
| `lookIn`        | 按显示的值（默认）还是按输入的内容和公式查找 | `'values' \| 'formulas'` |
| `scope`         | 当前工作表（默认）还是整个工作簿             | `'sheet' \| 'workbook'`  |

### 事务方法

| 方法                                                   | 说明                                                                                   |
| ------------------------------------------------------ | -------------------------------------------------------------------------------------- |
| `sortRange(range, keys, { header?, valueAt?, lang? })` | 排序区域里的行，`keys` 是 `{ col, order }` 列表；区域里有合并单元格时抛出 `RangeError` |
| `setFilter(range)`                                     | 给区域加上筛选，新区域会去掉原来的条件；`null` 去掉筛选                                |
| `filterColumn(col, rule, sheet?)`                      | 设置一列的筛选：`{ values }` 按值，`{ condition }` 按条件，`undefined` 去掉            |
