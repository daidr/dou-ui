# 电子表格

`@dou-ui/sheet` 提供电子表格 `DouSheet`：一张以单元格为单位编辑的网格，可以选择区域、直接输入、撤销重做，几十万个单元格也能流畅滚动。适合做预算表、排班表、数据录入这类"按格子填写"的界面。

只是按列展示一组记录、做排序和分页时，用 [Table 表格](/components/table) 更合适。

几个完整页面的写法见区块中的[部门预算](../blocks/budget)和[门店排班](../blocks/shifts)。

## 安装

电子表格是单独的包，需要和 `dou-ui` 一起使用：

```sh
bun add dou-ui @dou-ui/sheet
```

引入样式，再注册组件：

```ts
import 'dou-ui/style.css'
import '@dou-ui/sheet/style.css'
import { DouSheet } from '@dou-ui/sheet'

app.use(DouSheet)
```

## 基础用法

`v-model` 绑定一个工作簿：`sheets` 是工作表列表，每张表的 `cells` 是按行排列的二维数组，只有值的单元格直接写值，需要样式或数字格式时写成对象。完整的格式见[文档数据](./data)。

<DocDemo src="sheet/basic" column />

数字、日期和时间靠右，文字靠左，`TRUE` / `FALSE` 居中，和数字格式一样只影响显示，值本身不变。没有数字格式的数字放不下时，先减少小数位，再改用科学计数法（如 `1.23E+11`）显示，值本身不变；加宽列后恢复完整显示。

## 选择

点击选中一个单元格，拖动选中一片区域。按住 `Shift` 点击扩大当前区域，按住 `Ctrl` / `⌘` 点击再加一片区域。点击列标或行号选中整列、整行，点击左上角全选。拖到表格边缘时会自动滚动。

`v-model:selection` 读写选区：`ranges` 是选中的区域，`active` 是键盘所在的单元格，总在最后一片区域里。坐标从 0 开始，`formatRange` 把区域转成 `A1:C4` 这样的名字，`parseRange` 反过来。

<DocDemo src="sheet/selection" column />

触屏上单指滑动是滚动表格，轻点选中单元格，再点一次开始编辑；按住片刻后拖动选择区域。

## 编辑

选中单元格后直接输入就会替换它的内容，输入法也可以直接开始。双击或按 `F2` 编辑原来的内容。`Enter` 确认并移到下一行，`Tab` 确认并移到右边一格，`Esc` 取消，点到别处也会确认。`Alt` + `Enter` 在单元格里换行。

直接输入开始的编辑里，方向键会确认并移动，便于连续录入；按 `F2` 开始的编辑里，方向键移动光标。编辑中按 `F2` 在两种方式之间切换。

输入的内容按下面的规则读成值：

| 输入                                 | 写入的值                                     |
| ------------------------------------ | -------------------------------------------- |
| `1234`、`1,234.5`、`-3e2`            | 数字                                         |
| `12.5%`                              | `0.125`，没有格式时加上格式 `0.0%`           |
| `¥1,200`、`$12.50`、`-€3`            | 数字，加上货币格式 `¥#,##0`、`$#,##0.00`     |
| `2026-03-05`、`2026/3/5`、`2026.3.5` | 日期字符串 `'2026-03-05'`；可以带时间 `9:30` |
| `9:30`、`18:30:15`                   | 时间字符串 `'09:30'`、`'18:30:15'`           |
| `true`、`FALSE`                      | 布尔值                                       |
| `=SUM(A1:A3)`                        | 公式，显示计算结果，见[公式](./formulas)     |
| `'007`                               | 文字 `'007'`，开头的 `'` 表示按文字保存      |
| 其他                                 | 文字                                         |

日期和时间统一按 `'YYYY-MM-DD HH:mm'` 这样的标准写法保存。用其他写法输入时，会同时加上对应的格式，让单元格仍按输入的样子显示：输入 `2026/3/5` 保存为 `'2026-03-05'`，格式为 `yyyy/m/d`；输入 `9:30` 保存为 `'09:30'`，格式为 `h:mm`。格式里只有输入时带了前导 0 的部分才补零，`2026/12/5` 的格式是 `yyyy/m/d`，所以之后改成 1 月也显示为 `2026/1/5`。

单元格原来的样式和格式会保留，没有格式时才加上输入带来的格式。`Delete` 或 `Backspace` 清空选中区域的值，样式和格式不动。

`readonly` 只允许选择、浏览和复制，不能修改。代码里用 `history: false` 提交的修改（例如[协同编辑](./collaboration)时其他人的修改）仍然会生效。

触屏上编辑框的字号至少是 16px，避免手机在聚焦时自动放大页面。

### 撤销与重做

`Ctrl` / `⌘` + `Z` 撤销，`Ctrl` / `⌘` + `Shift` + `Z` 或 `Ctrl` + `Y` 重做，撤销后选区回到修改时的位置。也可以通过组件实例调用 `undo()`、`redo()`，用 `canUndo`、`canRedo` 控制按钮状态。`v-model` 被整个换成另一份数据时，撤销记录会清空。

### 用代码修改

`transact` 把多处修改合成一次提交，撤销时也作为一步：

```ts
sheet.value.transact((tr) => {
  tr.setValue('A5', '鼠标')
  tr.updateCell('B5', { value: 98, format: '#,##0' })
  tr.setValue("'表 2'!A1", '汇总') // 指定工作表
  tr.setValue({ row: 4, col: 2 }, true) // 用坐标，即 C5
  tr.setSize('col', 0, 140)
})
```

行和列也可以按显示的写法指定，数字仍是从 0 开始的序号：

```ts
sheet.value.transact((tr) => {
  tr.insertRows('5:6') // 在第 5 行前插入两行，等同 insertRows(4, 2)
  tr.deleteCols('B:C')
  tr.moveRows('2:3', '8') // 第 2、3 行移到原来的第 8 行之前
  tr.moveCells('A1:B4', 'D1') // 像剪切粘贴一样移动一块单元格
  tr.fill('A2', 'A2:A20', { mode: 'series' })
})
```

单元格用名字（`'A5'`）或从 0 开始的坐标（`{ row, col }`）指定，没写工作表时指当前显示的那张。要写到别的表，在名字前加 `表名!`，表名有空格时用单引号括起来；坐标则写成 `{ sheet, row, col }`，`sheet` 是工作表的序号、`id` 或名字。区域可以写 `'A1:C4'`、整列 `'B:D'`、整行 `'2:3'`。

每次修改，不论来自输入、撤销还是 `transact`，都会更新 `v-model` 并触发 `transaction` 事件。事件参数里的 `steps` 是这次修改的步骤，`inverse` 是撤销它的步骤，可以用来同步到服务端；另一端用 `applySheetSteps(doc, steps)` 应用。`meta.action` 说明修改的来源：

| `action`                 | 来源                                         |
| ------------------------ | -------------------------------------------- |
| `input`                  | 在单元格里输入                               |
| `paste`、`cut`           | 粘贴；粘贴剪切的内容（移动单元格）           |
| `fill`、`clear`          | 填充柄、`Ctrl` + `D` / `R`；清空内容         |
| `resize`、`hide`、`move` | 调整行高列宽；隐藏、取消隐藏；移动行列       |
| `merge`                  | 合并、取消合并单元格                         |
| `style`、`freeze`        | 工具栏或快捷键修改样式、格式；工具栏冻结行列 |
| `sheet`                  | 标签栏里新建、重命名、复制、移动、删除工作表 |
| `insert`、`delete`       | 插入、删除行列                               |
| `undo`、`redo`           | 撤销、重做                                   |
| `api`                    | 组件实例的 `transact`，没有指定 `action`     |

| 方法                                                                                  | 说明                                                                                                                                                           |
| ------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `getCell(cell)`                                                                       | 读取单元格，包括这次事务里已经做的修改                                                                                                                         |
| `setValue(cell, value)`                                                               | 写入值，保留样式和格式                                                                                                                                         |
| `updateCell(cell, patch)`                                                             | 修改单元格的部分字段，值为 `undefined` 的字段会被删除                                                                                                          |
| `setCell(cell, input)`                                                                | 整个替换单元格，`undefined` 清空                                                                                                                               |
| `clearValues(range)`                                                                  | 清空一片区域的值，保留样式                                                                                                                                     |
| `setSize('row' \| 'col', i, px, sheet?)`                                              | 设置行高、列宽，`undefined` 恢复默认，`0` 隐藏                                                                                                                 |
| `updateSheet(patch, sheet?)`                                                          | 修改工作表的名字、冻结、行列数                                                                                                                                 |
| `setCells(cell, block)`                                                               | 以 `cell` 为左上角写入一块单元格（二维数组）                                                                                                                   |
| `fill(from, to, { mode? })`                                                           | 用 `from` 的内容按填充柄的规则填满 `to`，`to` 要向一个方向延伸 `from`。`mode` 为 `auto`（默认，和拖动一样）、`series`（一个数字也逐个加一）或 `copy`（只复制） |
| `insertRows(at, count?, sheet?)`、`insertCols`                                        | 在 `at` 前插入空行（列），`at` 是序号或 `'5:6'`、`'C'` 这样的写法                                                                                              |
| `deleteRows(at, count?, sheet?)`、`deleteCols`                                        | 删除行（列）及其中的单元格和尺寸                                                                                                                               |
| `moveRows(lines, to, sheet?)`、`moveCols`                                             | 把行（列）移到 `to` 之前，`to` 按移动前编号；`lines` 是序号、`'2:3'` 或 `{ from, count }`                                                                      |
| `moveCells(range, cell)`                                                              | 把一块单元格移到以 `cell` 为左上角的位置，原位置清空                                                                                                           |
| `mergeCells(range)`、`unmergeCells(range)`                                            | 合并区域，只保留左上角的内容；取消区域碰到的所有合并                                                                                                           |
| `addSheet(sheet?, index?)`、`removeSheet(sheet)`                                      | 新建、删除工作表，见[多个工作表](#多个工作表)                                                                                                                  |
| `renameSheet(sheet, name)`、`moveSheet(sheet, index)`、`duplicateSheet(sheet, name?)` | 重命名、移动、复制工作表                                                                                                                                       |
| `styleCells(range, patch)`、`formatCells(range, format)`                              | 修改区域的样式、数字格式，见[改样式](#改样式)                                                                                                                  |
| `setStyle(name, style)`                                                               | 添加、修改或（传 `undefined`）删除一个命名样式                                                                                                                 |
| `setMeta({ history, group, action })`                                                 | `history: false` 不进入撤销记录；同一 `group` 的连续修改合并为一步；`action` 见上表                                                                            |

插入、删除和移动行列，以及移动单元格时，所有工作表里指向这些单元格的公式引用都会随之改写：插入行后 `=A5` 变成 `=A6`，区域 `A1:A5` 在中间插入一行后变成 `A1:A6`；删除被引用的单元格后引用变成 `#REF!`，区域只删除一部分时缩小。和复制不同，这时 `$A$1` 这样的固定引用也会跟着改。

步骤里的工作表用 `id` 记录，没有 `id` 时用名字，所以在另一端应用时不受工作表顺序影响。

组件实例上还有 `select('B2:C4')` 选中并滚动到区域（也可以是 `'B:B'`、`'3:3'`）、`scrollTo('H200')`、`edit('B2')` 打开编辑框、`focus()`、`showSheet(sheet)` 切换工作表和 `toCSV(options?)`。

## 复制与粘贴

`Ctrl` / `⌘` + `C` 复制选区，`Ctrl` / `⌘` + `X` 剪切，`Ctrl` / `⌘` + `V` 粘贴，也可以用右键菜单。复制的区域会显示虚线框，按 `Esc` 取消。

复制时剪贴板里同时放入两种内容：用制表符分隔、按单元格显示的文字的纯文本，以及带简单格式的表格。所以复制到其他表格软件、文档或网页时能保留行列；从它们复制过来时，表格和制表符分隔的文字都能识别，每个单元格按输入的规则读成值，比如 `12%` 读成 `0.12` 并加上百分比格式，目标单元格原来的样式保留。从这张表或另一个 `DouSheet` 复制的内容会原样粘贴，包括格式、样式和备注。

- 复制一个单元格，粘贴时填满整个选区。
- 选区正好是复制内容的整数倍时，重复填满选区；否则从选区左上角开始粘贴，并选中粘贴的区域。
- 复制的公式粘贴后，没有 `$` 的引用随位置移动，`=A1*2` 向下粘贴一行变成 `=A2*2`。
- 剪切后粘贴是移动：原位置被清空，移动的公式保持不变，其他公式里指向这些单元格的引用改成新的位置；指向被覆盖的单元格的引用变成 `#REF!`。

右键菜单里的复制、粘贴用浏览器的剪贴板接口，第一次粘贴时浏览器可能会询问权限；不允许读取剪贴板时，表格会提示改用快捷键。组件实例的 `copy()`、`cut()`、`paste(clip?)` 做同样的事，`paste` 也可以直接传入 `parseClip` 读出的内容；`formatClip(clip, { locale, text })` 则把单元格转成剪贴板里的文字和表格，`text` 可以给出某个单元格的文字。复制时单元格按显示的文字写成纯文本，带类型的单元格用类型的 `format`。

写入之前会触发 `paste` 事件。`event.clip.cells` 是要粘贴的单元格，`event.range` 是粘贴的位置，可以修改或替换 `event.clip`，也可以调用 `event.preventDefault()` 取消粘贴：

```vue
<DouSheet v-model="book" @paste="onPaste" />
```

```ts
import type { SheetPasteEvent } from '@dou-ui/sheet'

function onPaste(event: SheetPasteEvent) {
  // 去掉粘贴进来的文字首尾的空格
  event.clip = {
    ...event.clip,
    cells: event.clip.cells.map((row) =>
      row.map((cell) => (typeof cell === 'string' ? cell.trim() : cell)),
    ),
  }
}
```

## 填充

选区右下角的小方块是填充柄，拖动它把选区延伸到相邻的单元格，按选区里的内容推算后面的值：

| 选区内容                            | 拖出的值                               |
| ----------------------------------- | -------------------------------------- |
| 一个数字 `5`                        | 复制：`5, 5, 5`                        |
| 等差的数字 `1, 3`                   | 继续：`5, 7, 9`；不等差时按趋势线推算  |
| 日期 `2026-10-30`                   | 每次加一天                             |
| 每月同一天 `2026-01-15, 2026-02-15` | 每次加一个月                           |
| 月末 `2026-01-31, 2026-02-28`       | 每月最后一天：`2026-03-31, 2026-04-30` |
| 时间 `9:00`、`9:00, 9:30`           | 每次加一小时，或按间隔继续             |
| 带数字的文字 `第 1 周`              | `第 2 周, 第 3 周`                     |
| 其他文字、公式                      | 依次重复，公式的引用随位置移动         |

<DocDemo src="sheet/fill" column />

向上、向左拖时反向推算。拖动时旁边会显示最后一格将要填入的值。按住 `Ctrl` / `⌘`（或 `Alt`）做和默认相反的事：会继续的内容改为复制，一个数字改为逐个加一。把填充柄拖回选区内会清空经过的单元格。双击填充柄向下填充到左右相邻一列数据的末尾。

代码里用 `continueValues(values, count, { mode })` 得到填充柄会给出的值，`fillContinues(values)` 判断默认是继续还是复制。

`Ctrl` / `⌘` + `D` 用选区第一行向下填充，`Ctrl` / `⌘` + `R` 用第一列向右填充，都是直接复制；只选了一行时复制上面一行。

触屏上填充柄显示为圆点，可按的范围比圆点大，按住直接拖动即可，不需要长按。

## 行和列

拖动列标右边线或行号下边线调整宽度和高度，双击边线按内容自动调整。选中多列（多行）时调整其中一列，所有选中的列一起改变。拖到几乎为 0 会隐藏这一列。

选中整行（整列）后，拖动行号（列标）可以把它们移到别处，拖动时显示放下的位置。

右键单元格、行号或列标打开菜单。右键行号，或选中整行后右键单元格，菜单里是插入、删除、隐藏和取消隐藏行；列也一样。右键普通单元格时，插入和删除分别收在“插入”“删除”两个子菜单里，行和列都有。插入的数量和选中的行数（列数）一样；会删光所有行（列）时不提供删除。隐藏的行和列在行号、列标之间显示为一条双线，选中它两边的行（列）后在菜单里取消隐藏。触屏上长按单元格不拖动，松开后打开菜单；键盘上按菜单键或 `Shift` + `F10`。

`menu` 属性可以修改菜单：它收到表格准备显示的菜单项和打开的位置，返回实际显示的菜单项。可以删掉、调整顺序，或加上自己的菜单项：

```vue
<script setup lang="ts">
import type { SheetMenuContext, SheetMenuItem } from '@dou-ui/sheet'

function menu(items: SheetMenuItem[], context: SheetMenuContext) {
  const own: SheetMenuItem = {
    key: 'note',
    label: '添加备注',
    divided: true,
    run: () => addNote(context.selection.active),
  }
  return context.area === 'cell' ? [...items, own] : items
}
</script>

<template>
  <DouSheet v-model="book" :menu="menu" />
</template>
```

`context.area` 是 `cell`、`row`、`col` 或 `corner`，整行、整列被选中时按行号、列标算；`context.selection` 是菜单作用的选区。菜单项的 `children` 显示为子菜单。

插入、删除发生在冻结区域内时，冻结的行数和列数会跟着变化。工作表设置了 `rowCount`、`colCount` 时，行数、列数也随之增减。

## 合并单元格

工作表的 `merges` 列出合并的区域，例如 `['A1:B1']`。合并后显示左上角单元格的内容，其余单元格被盖住。选区碰到合并区域时会扩大到把它整个包含进来，方向键移动时把合并区域当作一个单元格。

选中区域后，在右键菜单里选“合并单元格”或“取消合并”；用代码修改时调用 `tr.mergeCells('A1:B2')`、`tr.unmergeCells('A1')`。合并时只保留左上角的内容，其余单元格的值被清空（样式保留），表格会提示清空了几个单元格，撤销可以恢复；用代码合并时传 `{ keep: true }` 可以把它们留在合并单元格下面，取消合并后重新显示。插入、删除、移动行列时，合并区域跟着移动和伸缩，缩到只剩一个单元格时自动取消。

## 单元格类型

单元格的 `type` 决定值怎么显示、怎么编辑。内置三种：

| `type`     | 显示                                                      | 编辑                                                                                                                                                      |
| ---------- | --------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `date`     | 和普通日期一样，按 `format` 显示                          | 输入日期，或在单元格下方的日历里点选；原有的时间部分保留。除了普通单元格认识的写法，还认 `11/30`、`11-30`、`11月30日`、`2026年11月30日`，没写年份时是今年 |
| `select`   | 选项的值，显示为标签，颜色取选项的 `tone`，没有时为中性色 | 在下方的列表里选，输入文字会筛选列表，方向键移动，Enter 选定                                                                                              |
| `checkbox` | 勾选框，值为 `true` 或 `false`                            | 点击勾选框、按空格、双击或按 F2 切换。空格切换选区里所有勾选框：状态相同时一起切换，有勾有不勾时全部勾上                                                  |

`select` 的选项写在工作簿的 `types` 里，起一个名字，单元格用这个名字作 `type`，和命名样式的用法一样。选项可以是值，也可以是 `{ value, tone }`：

```ts
const book = {
  types: {
    status: {
      type: 'select',
      options: [
        '未开始',
        { value: '进行中', tone: 'primary' },
        { value: '已完成', tone: 'success' },
      ],
    },
  },
  sheets: [{ name: '任务', cells: [[{ value: '进行中', type: 'status' }]] }],
}
```

选中带列表或日历的单元格时，右侧会出现一个展开按钮；也可以按 `Alt` + `↓` 展开。输入的文字和选项一致时（不区分大小写）记为该选项。读不懂的值照常写入，比如日期单元格里的“明天”、不在选项里的文字，这样的单元格右上角会有一个红色小三角，鼠标悬停时显示原因，读屏也会读出。在手机上展开列表或日历时不会弹出键盘。

<DocDemo src="sheet/types" column />

要加自己的单元格类型，比如进度条、评分，见[扩展](./extensions)。

## 排序与筛选

右键菜单的“排序”按当前单元格所在的列排列行：选中多行时排列选中的行；只选中一个单元格时，在筛选区域里就排列筛选区域，否则排列它周围连成一片的单元格，第一行都是文字时当作表头留在原处。数字排在文字前面，文字按当前语言的习惯排列（中文按拼音），空单元格不论升序降序都排在最后，值相同的行保持原来的顺序。公式跟着所在的行移动，引用像复制时一样跟着移动。含有合并单元格的区域不能排序。

右键菜单的“筛选”或 `Ctrl` + `Shift` + `L`（Mac 上是 `⌘` + `⇧` + `L`）给选中的区域加上筛选，只选中一个单元格时用它周围的一片单元格。区域的第一行是表头，每个表头右侧出现筛选按钮，再按一次取消筛选。点击按钮或在表头上按 `Alt` + `↓` 打开筛选面板：

- 升序、降序：只排列筛选区域里的行，表头不动，按钮上显示排序方向。
- 按值：勾选要显示的值，可以搜索；列出的值只来自其他列筛选后留下的行。
- 按条件：等于、大于、包含、开头是、为空等，数字按大小比较，文字不区分大小写。

被筛掉的行只是不显示，数据和行高都不变，清除筛选后重新显示。筛选后修改单元格，不再符合条件的行会留在原处，直到下次改动筛选条件时才隐藏，避免正在编辑的行突然消失。

<DocDemo src="sheet/filter" column />

筛选保存在工作表的 `filter` 里，见[文档数据](./data#筛选)。用代码排序和筛选时调用事务的方法：

```ts
sheet.value.transact((tr) => {
  tr.sortRange('A1:G25', [{ col: 5, order: 'desc' }], { header: true })
  tr.setFilter('A1:G25')
  tr.filterColumn(1, { values: ['上海', '杭州'] })
  tr.filterColumn(3, { condition: { op: 'ge', value: 10 } })
})
```

`sortRange` 的 `valueAt(row, col)` 可以提供每个单元格用来比较的值，不提供时按单元格里写的值比较，公式按公式文字比较；表格里的排序按计算结果比较。

## 条件格式

条件格式按单元格的值改变它的样子，比如把没完成目标的数字标红。规则保存在工作表的 `conditionalFormats` 里，每条规则作用于一个区域，也可以是几个区域组成的数组：

- `when`：满足条件的单元格使用 `style`，条件和筛选的写法一样，另外可以用 `between` 和 `notBetween`。
- `formula`：公式结果为 `TRUE` 或非零数字时使用 `style`。公式按区域左上角单元格书写，套用到其他单元格时像复制公式一样移动引用，用 `$` 固定不动的部分。
- `top`、`bottom`：最大或最小的几个数字，加上 `percent: true` 时按百分比计算。
- `average`：高于（`'above'`）或低于（`'below'`）平均值的数字。
- `duplicates`、`unique`：重复出现的值，或只出现一次的值，按显示的文字比较，不区分大小写。
- `scale`：色阶，按数字大小在两种或三种颜色之间填充。
- `bar`：数据条，按数字大小在单元格里画出长度不同的条，负数从零点向左画，颜色相同。

`style` 可以写样式，也可以写 `styles` 里的样式名。颜色可以用主题的语义色名（跟着暗色模式变化），也可以写任意 CSS 颜色。

<DocDemo src="sheet/conditional" column />

上面的例子带了只有条件格式按钮的工具栏，可以选中一列试着添加规则。

多条规则给同一个单元格设置同一项样式时，排在前面的规则生效；规则的样式会覆盖单元格本身的样式。插入或删除行列时，规则的区域和公式跟着移动。用代码修改时调用事务的方法：

```ts
sheet.value.transact((tr) => {
  tr.addConditionalFormat({
    range: 'E2:E9',
    when: { op: 'lt', value: 1 },
    style: { tone: 'danger' },
  })
  tr.clearConditionalFormats('E2:E9') // 移除与这个区域重叠的规则
})
```

## 数据验证

数据验证限制单元格里能填什么，比如只能从列表里选，或者只能填 1 到 5 的整数。规则保存在工作表的 `validations` 里，每条规则作用于一个区域，也可以是几个区域组成的数组：

- `list`：从列表里选。可以直接写选项，也可以引用一片单元格，如 `'=$G$2:$G$5'`、`'=城市!A2:A20'`。这些单元格会像下拉类型一样带一个展开按钮。
- `when`：满足条件，写法和条件格式一样。条件里写的是数字时，单元格必须是数字；加上 `integer: true` 时必须是整数。
- `formula`：公式结果为 `TRUE` 或非零数字时符合，按区域左上角单元格书写，和条件格式的公式一样移动引用。

空单元格总是符合规则。每条规则还可以写：

- `strict`：输入不符合时是否拒绝，默认 `true`。拒绝时值不会写入，表格下方会提示原因，编辑框保持打开；点到别处时放弃这次输入。设为 `false` 时值照常写入，只在单元格角上标记。
- `message`：不符合时的提示，不写时说明规则，比如“请输入整数，介于 1 和 5 之间”。
- `prompt`：选中单元格时在旁边显示的提示，读屏也会读出。

粘贴和填充的值不检查，不符合的单元格同样会被标记：鼠标悬停时显示原因，选中时在旁边的提示里显示原因，读屏会读出“无效”和原因。`findInvalid()` 列出所有不符合规则的单元格，可以在提交前检查：

<DocDemo src="sheet/validation" column />

工具栏的“数据验证”按钮打开当前单元格所在的规则，没有时为选区新建一条；选了几个区域时，新规则包含所有区域。对话框里的区域可以写几个，用逗号或空格隔开。插入或删除行列时，规则的区域、公式和列表引用跟着移动。用代码修改时调用事务的方法：

```ts
sheet.value.transact((tr) => {
  tr.addValidation({ range: 'D2:D20', when: { op: 'between', value: 1, to: 5 }, integer: true })
  tr.clearValidations('D2:D20') // 移除与这个区域重叠的规则
})
```

## 工具栏

把 `DouSheetToolbar` 放进 `header` 插槽，表格上方会出现格式工具栏。按钮作用于选区，按下的状态跟着当前单元格（键盘所在的那一格）：

- 撤销、重做。
- 数字格式：常规、数字、百分比、货币、日期、时间、文本，旁边是两种小数位按钮。没有格式的数字按显示的位数开始加减。
- 加粗、斜体、下划线、删除线。
- 文字颜色和填充颜色：主题的五种语义色，会跟着暗色模式变化；“自定义颜色”可以选任意颜色，原样使用。
- 水平对齐、垂直对齐和自动换行。没有设置对齐时，按下的是单元格本来的对齐方式，比如数字靠右。
- 合并单元格：选区是合并单元格时按钮处于按下状态，再按一次取消合并。
- 冻结：冻结首行、首列，或冻结到当前单元格所在的行、列。
- 排序和筛选：同右键菜单里的“排序”和“筛选”。
- 条件格式：突出显示大于、小于、介于、等于某个值或包含某段文字的单元格，以及重复值、按公式判断、前几项、后几项、高于或低于平均值；给选区加数据条或色阶；清除规则，或在“管理规则”里编辑、调整顺序、删除规则，见[条件格式](#条件格式)。
- 数据验证：设置当前单元格或选区的验证规则，见[数据验证](#数据验证)。
- 清除格式：去掉样式和数字格式，值不变。

<DocDemo src="sheet/toolbar" column />

用鼠标点按钮后，键盘仍在表格里，可以接着输入；用键盘在工具栏里操作时（`Tab` 进入，左右方向键移动），焦点留在工具栏。工具栏放不下时横向滚动。只读时按钮都不可用。

`tools` 指定显示哪些按钮和顺序，`'|'` 是分隔线；`start`、`end` 插槽可以在前后加自己的按钮：

```vue
<DouSheetToolbar :tools="['undo', 'redo', '|', 'bold', 'italic', '|', 'color', 'fill']">

    <DouButton variant="ghost" @click="exportCSV">导出</DouButton>
  </template>
</DouSheetToolbar>
```

可用的名字有 `undo`、`redo`、`format`、`decimals`、`bold`、`italic`、`underline`、`strike`、`color`、`fill`、`align`、`valign`、`wrap`、`merge`、`freeze`、`sort`、`filter`、`conditional`、`validation`、`clear`。`formats` 替换数字格式菜单里的选项，每项是 `{ label, format, example? }`，`example` 是菜单里用这个格式显示的示例值。

显示单元格地址和公式的编辑栏是 `DouSheetFormulaBar`，同样放在 `header` 插槽里，可以和工具栏一起用，见[公式](./formulas#编辑栏)。

工具栏只用了 `useSheet()` 提供的方法，自己做工具栏时可以直接调用：`styleAt(cell)` 读取单元格的样式，`styleSelection(patch)` 修改选区的样式，`formatSelection(format)` 设置数字格式，`clearFormatting()`、`merge()`、`unmerge()`，见[扩展](./extensions)。

### 改样式

`tr.styleCells(range, patch)` 把 `patch` 叠加到区域里每个单元格原有的样式上，字段设为 `undefined`（或 `false`）表示去掉这一项，`patch` 为 `null` 时去掉整个样式。改完后看起来一样的单元格共用一个样式：`styles` 里有一样的就用它，没有就新建一个，名字是 `s1`、`s2` 这样的编号。所以给一列里样式各不相同的单元格加粗，每种原有样式各得到一个加粗的版本，不会每格存一份。

```ts
sheet.value.transact((tr) => {
  tr.styleCells('A1:E1', { bold: true, fill: 'neutral' })
  tr.styleCells('C:D', { align: 'right' }) // 整列，到工作表的最后一行为止
  tr.formatCells('C2:D20', '¥#,##0.00')
  tr.formatCells('C2:D20', (format, value) => changeDecimals(format, value, 1)) // 多一位小数
})
```

`changeDecimals(format, value, by)` 返回多 `by` 位（为负时少）小数的格式，比如 `0.00` 变成 `0.000`、`0.0%` 变成 `0%`；`format` 为空时从 `value` 显示的位数开始。日期、时间和文本格式原样返回。

## 多个工作表

`modelValue.sheets` 里的每一项是一个工作表，`v-model:active-sheet` 是显示的工作表的序号。把 `DouSheetTabs` 放进 `footer` 插槽，表格下方会出现工作表标签：

- 点标签切换工作表，`+` 在当前工作表后面新建一个。
- 双击标签或按 `F2` 重命名，名字不能为空，也不能和别的工作表重名。
- 右键（手机上点一下当前的标签）打开菜单，可以重命名、创建副本、左右移动和删除。
- 拖动标签调整顺序，手机上按住一会儿再拖。
- 标签获得焦点后，左右方向键切换工作表，`Home` / `End` 到第一个、最后一个，`Enter` 回到表格。

这些操作都可以撤销，只读时只能切换。不需要 `+` 按钮时设置 `:addable="false"`。表格里按 `Ctrl` + `Page Up` / `Page Down` 也能切换工作表。每个工作表各自记住选区和滚动位置，切回来时恢复。

<DocDemo src="sheet/sheets" column />

`header` 插槽在表格上方，适合放工具栏。插槽里的组件可以用 `useSheet()` 读写表格，所以标签栏也可以照着 `DouSheetTabs` 自己做。

在代码里管理工作表：

```ts
sheet.value.transact((tr) => {
  tr.addSheet({ name: '十一月' }) // 加在最后，也可以传第二个参数指定位置
  tr.addSheet({ name: tr.uniqueName('九月') }) // 名字被占用时自动编号，得到“九月 (2)”
  tr.renameSheet('九月', '九月 上海')
  tr.duplicateSheet('十月') // 名为“十月 (2)”，放在原工作表后面
  tr.moveSheet('十一月', 0)
  tr.removeSheet('汇总')
})
sheet.value.showSheet('十一月')
```

名字不能和已有的工作表重复，否则会抛出错误；`tr.uniqueName(name)` 返回一个没被占用的名字。`addSheet()` 不传名字时用 `Sheet1`、`Sheet2` 这样的名字，不随语言变化；标签栏的 `+` 按当前语言起名，比如“工作表3”。

重命名后，所有公式里指向它的引用会改成新名字，比如 `=九月!B2` 变成 `='九月 上海'!B2`；删除后，指向它的引用变成 `#REF!`。工作簿至少保留一个工作表，删除最后一个时不做任何事。增删和移动工作表后，表格继续显示原来那一张；它被删除时显示原来位置上的那一张。

## CSV

`readCSV(text, options?)` 把 CSV 读成二维数组，可以直接作为工作表的 `cells`，比如 `tr.addSheet({ name, cells: readCSV(text) })`。数字、日期、百分比和 `TRUE` / `FALSE` 按输入时的规则识别，比如 `2026/3/5` 读成日期并保留写法；`007`、很长的卡号这类带前导零或超过 15 位的数字保持文字，以免丢失。以 `=` 开头的内容默认按文字读入（存成 `'=…`），不会变成公式。

| 读取选项    | 说明                                                                                   | 默认值                               |
| ----------- | -------------------------------------------------------------------------------------- | ------------------------------------ |
| `delimiter` | 分隔符                                                                                 | 从内容判断：逗号、分号、制表符或竖线 |
| `typed`     | 识别数字、日期等；`false` 时所有内容都是文字                                           | `true`                               |
| `decimal`   | 小数点。`','` 时 `1,5` 读成 1.5、`1.280,5` 读成 1280.5；用分号分隔的文件通常是这种写法 | 分隔符是 `;` 时为 `','`，否则 `'.'`  |
| `formulas`  | 以 `=` 开头的内容读成公式                                                              | `false`                              |

组件实例的 `toCSV()` 把当前工作表写成 CSV，内容和单元格显示的一致（带格式，单元格类型按它自己的写法）。只到最后一个有数据的行和列，用 `range` 可以只导出一部分，`sheet` 指定别的工作表。导出的文件要给表格软件打开时，加上 `bom: true`，否则中文可能被当成其他编码。

以 `=`、`+`、`-`、`@` 开头的文字在表格软件里打开时会被当成公式执行，这可能被用来插入恶意链接或命令。导出时默认在这样的文字前面加上 `'`，数字不受影响；`formatted: false` 时表格里的公式按原文写出，不加 `'`，可以用 `readCSV(text, { formulas: true })` 读回来。加上的 `'` 会留在文字里，所以导出的文件如果只是给 `readCSV` 原样读回，应设置 `escapeFormulas: false`。确定文件不会被表格软件打开时，可以设置 `escapeFormulas: false` 原样写出。

<DocDemo src="sheet/csv" column />

| 导出选项         | 说明                                                                                    | 默认值       |
| ---------------- | --------------------------------------------------------------------------------------- | ------------ |
| `delimiter`      | 分隔符                                                                                  | `','`        |
| `range`          | 只导出这片区域，如 `'A1:D20'`、`'B:D'`                                                  | 有数据的部分 |
| `formatted`      | 写单元格显示的文字；`false` 写存储的值（`1280`、`2026-03-05`、公式原文）                | `true`       |
| `newline`        | 行之间的换行                                                                            | `'\r\n'`     |
| `bom`            | 在开头加上字节顺序标记                                                                  | `false`      |
| `escapeFormulas` | 在以 `=`、`+`、`-`、`@` 开头的文字前加 `'`                                              | `true`       |
| `locale`         | 日期格式里星期等文字的语言（`toCSV` 用当前语言）                                        | —            |
| `text`           | `(input) => string \| undefined`，自己决定单元格写出的文字，返回 `undefined` 时按格式写 | —            |
| `sheet`          | 要导出的工作表，序号、`id` 或名字（仅 `toCSV`）                                         | 当前显示的   |

不经过组件时，`sheetToCSV(sheetData, options)` 做同样的事，只是单元格类型按值本身写出（可以用 `text` 补上）。`parseCSV(text, delimiter?)` 只拆分字段，不识别类型；`detectDelimiter(text)` 返回判断出的分隔符。

## 导出图片与打印

组件实例的 `toSVG()` 和 `toPNG()` 把当前工作表画成图片，样子和表格里一致：样式、合并单元格、条件格式的颜色和数据条、勾选框和选项标签都会画出来，颜色跟随当前的亮暗主题，选区不会画进去。`toSVG()` 返回 SVG 文档的字符串，文字仍是文字，可以在设计软件里继续编辑；`toPNG()` 返回 PNG 的 `Blob`。

`print()` 打开浏览器的打印对话框。表格只渲染看得见的部分，直接打印页面只能打出一屏，`print()` 则会打印整张表：纸张是 A4，表格比竖向的纸宽时自动横向；一页放不下时按先向下、再向右的顺序分页，冻结的行和列在每一页重复，页脚有页码。打印总是使用浅色主题。

| 选项          | 说明                                                       | 默认值                   |
| ------------- | ---------------------------------------------------------- | ------------------------ |
| `range`       | 只画这片区域，如 `'A1:F20'`、`'A:D'`                       | 有数据和合并单元格的部分 |
| `headers`     | 画出列标和行号                                             | `false`                  |
| `gridlines`   | 画出格线                                                   | 跟随表格的 `gridlines`   |
| `background`  | 填充底色；`false` 时为透明底，便于放到其他背景上（仅图片） | `true`                   |
| `pixelRatio`  | 每个 CSS 像素对应的图片像素（仅 `toPNG`）                  | `2`                      |
| `title`       | 每页顶部的标题（仅 `print`）                               | —                        |
| `orientation` | 纸张方向，`'portrait'` 或 `'landscape'`（仅 `print`）      | 按表格宽度选择           |

隐藏的行列和被筛选掉的行不会画出来。自定义的单元格类型按 `format` 返回的文字画出。浏览器对画布的尺寸有限制（每边 16384 像素，iOS 上总共约 1677 万像素），区域很大时 `toPNG()` 会自动降低 `pixelRatio`，降到 1 仍然放不下时会抛出 `RangeError`。这时可以用 `range` 分几次导出，或者改用 `toSVG()`、`toCSV()`。

方法只返回内容，下载由你决定，例如：

```ts
const blob = await grid.value.toPNG()
const url = URL.createObjectURL(blob)
const link = Object.assign(document.createElement('a'), { href: url, download: '门店.png' })
link.click()
URL.revokeObjectURL(url)
```

## 大量数据

表格横向和纵向都只渲染看得见的单元格。修改只复制改动的那一行，其余行原样共享，所以只有改动的行会重新绘制；滚动时也只绘制新进入视野的行。下面是 1 万行 × 20 列、共 20 万个单元格的表：
