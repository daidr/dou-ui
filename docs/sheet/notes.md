# 批注与链接

单元格可以带一段批注，也可以带一个链接。几个人之间的讨论用[评论](./comments)，它有作者、回复，可以标记为已解决。

## 批注

批注写在单元格的 `note` 里。带批注的单元格右上角有一个小三角。

```ts
const cells = [[{ value: '场地', note: '上海展览中心 2 号厅，含两天布展。' }]]
```

<DocDemo src="sheet/notes" column />

- 鼠标停在单元格上时，批注显示在单元格旁边，移到批注上可以选中和复制其中的文字。
- 用方向键移到带批注的单元格，停一会儿也会显示。触屏上点一下单元格就会显示。
- 选中其他单元格、滚动或按 `Esc` 时收起。读屏读单元格时会一起读出批注。

## 编辑批注

在右键菜单里选“插入批注”（已有批注时是“编辑批注”），或者按 `Shift` + `F2`，单元格旁边会出现输入框。

- `Ctrl` / `⌘` + `Enter` 或点“保存”保存，`Esc` 或点“取消”放弃，点到别处时直接保存。
- 批注清空后保存就会删除。选区里有批注时，菜单里还有“删除批注”。
- 组件实例的 `editNote(cell?)` 选中单元格并打开输入框，可以接在自己的按钮上。

批注跟着单元格走：

- 合并单元格的批注写在它左上角的单元格上。
- 清除内容（`Delete`）不删除批注。
- 复制粘贴、填充、排序时批注跟着单元格移动。
- CSV 和导出的图片里不包含批注。
- 只读的表格可以查看批注，不能修改。

## 链接

`link` 是单元格的链接地址，单元格的值可以是任何内容。带链接的单元格文字显示为强调色并加下划线。

```ts
const cells = [
  [
    { value: '门店主页', link: 'https://ui.daidr.me' },
    { value: '看汇总', link: '#汇总!B2' },
  ],
]
```

<DocDemo src="sheet/links" column />

链接可以是：

- 网址（`https://`、`http://`），在新标签页打开。
- `mailto:`、`tel:` 地址。
- `#` 加单元格引用，指向工作簿里的位置，比如 `'#汇总!B2'`，打开时切到那个工作表并选中那片区域。指向的工作表不存在时，表格下方会提示。

`javascript:` 这类可以运行脚本的地址不会被打开，写进 `link` 也只当作普通文字。

## 打开链接

选中带链接的单元格时，下方显示链接地址，点地址打开链接。按住 `Ctrl` / `⌘` 点单元格也会打开。

打开之前触发 `linkOpen` 事件。调用 `event.preventDefault()` 后表格不再自己打开，可以改用应用的路由，或者先让用户确认：

```ts
import type { SheetLinkOpenEvent } from '@dou-ui/sheet'

function onLinkOpen(event: SheetLinkOpenEvent) {
  if (event.target.kind === 'web' && event.target.href.startsWith(location.origin)) {
    event.preventDefault()
    router.push(event.target.href.slice(location.origin.length))
  }
}
```

`linkTarget(link)` 返回链接指向哪里，打不开的链接返回 `null`，可以用来做自己的链接按钮。

## 编辑链接

在右键菜单里选“插入链接”（已有链接时是“编辑链接”），或者按 `Ctrl` / `⌘` + `K`，单元格下方出现输入框，可以修改显示的文本和链接地址。

- `Enter` 或点“保存”保存，`Esc` 或点“取消”放弃。地址清空后保存就会删除链接。
- “删除链接”去掉选区里所有的链接，单元格的值保留。
- 组件实例的 `editLink(cell?)` 选中单元格并打开输入框。

在单元格里直接输入 `https://` 或 `mailto:` 开头的地址时，它会自动成为链接。之后重新输入时，输入的还是地址就换成新地址，不是地址就去掉链接。用输入框或代码设置的链接，重新输入值时保留。

## 用公式生成链接

公式 `HYPERLINK(地址, 名称)` 让单元格成为链接，单元格显示名称，不写名称时显示地址。地址可以来自其他单元格，比如 `=HYPERLINK(A2, "下载")`。

这样的链接由公式决定，要改就改公式。在输入框里填的地址会写进单元格的 `link`，优先于公式给出的地址。

## 复制与导入导出

- 复制带链接的单元格时，链接一起复制，粘贴到其他程序里也是链接；从网页或其他程序复制来的链接同样保留。
- 导入导出 xlsx 时保留链接，见[导入导出 xlsx](./xlsx)。

## API

### 事务方法

| 方法                         | 说明                                |
| ---------------------------- | ----------------------------------- |
| `setNote(cell, text)`        | 设置批注，空文字或 `undefined` 删除 |
| `clearNotes(range)`          | 删除一片区域里的批注                |
| `updateCell(cell, { link })` | 设置链接，`link: undefined` 删除    |

### SheetLinkOpenEvent

| 属性               | 说明                                                                       | 类型                  |
| ------------------ | -------------------------------------------------------------------------- | --------------------- |
| `link`             | 单元格的链接                                                               | `string`              |
| `target`           | 链接指向哪里：`{ kind: 'web', href }` 或 `{ kind: 'cell', sheet?, range }` | `SheetLinkTarget`     |
| `cell`             | 单元格：工作表的序号、行和列                                               | `{ sheet, row, col }` |
| `preventDefault()` | 不让表格自己打开                                                           | `() => void`          |
| `defaultPrevented` | 是否已调用 `preventDefault()`                                              | `boolean`             |
