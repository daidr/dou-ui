# 条件格式与数据验证

条件格式按单元格的值改变它的样子，数据验证限制单元格里能填什么。两种规则都按区域保存在工作表里。

## 条件格式

规则保存在工作表的 `conditionalFormats` 里，每条规则作用于一个区域，也可以是几个区域组成的数组。下面的例子带了只有条件格式按钮的工具栏，可以选中一列试着添加规则。

规则有这些种类：

- `when`：满足条件的单元格使用 `style`。条件和筛选的写法一样，另外可以用 `between` 和 `notBetween`。
- `formula`：公式结果为 `TRUE` 或非零数字时使用 `style`。公式按区域左上角单元格书写，套用到其他单元格时像复制公式一样移动引用，用 `$` 固定不动的部分。
- `top`、`bottom`：最大或最小的几个数字，加上 `percent: true` 时按百分比计算。
- `average`：高于（`'above'`）或低于（`'below'`）平均值的数字。
- `duplicates`、`unique`：重复出现的值，或只出现一次的值，按显示的文字比较，不区分大小写。
- `scale`：色阶，按数字大小在两种或三种颜色之间填充。
- `bar`：数据条，按数字大小在单元格里画出长度不同的条，负数从零点向左画。

`style` 可以写样式，也可以写 `styles` 里的样式名。颜色可以用主题的语义色名（跟着暗色模式变化），也可以写任意 CSS 颜色。

- 多条规则给同一个单元格设置同一项样式时，排在前面的规则生效。
- 规则的样式覆盖单元格本身的样式。
- 插入或删除行列时，规则的区域和公式跟着移动。

规则的完整写法见[文档数据 · 条件格式](./data#条件格式)。

## 数据验证

规则保存在工作表的 `validations` 里，每条规则作用于一个区域，也可以是几个区域组成的数组。

<DocDemo src="sheet/validation" column />

规则有这些种类：

- `list`：从列表里选。可以直接写选项，也可以引用一片单元格，如 `'=$G$2:$G$5'`、`'=城市!A2:A20'`。这些单元格会像下拉类型一样带一个展开按钮。
- `when`：满足条件，写法和条件格式一样。条件里写的是数字时，单元格必须是数字；加上 `integer: true` 时必须是整数。
- `formula`：公式结果为 `TRUE` 或非零数字时符合，和条件格式的公式一样移动引用。

每条规则还可以写：

- `strict`：输入不符合时是否拒绝，默认 `true`。拒绝时值不会写入，表格下方提示原因，编辑框保持打开；点到别处时放弃这次输入。设为 `false` 时值照常写入，只在单元格角上标记。
- `message`：不符合时的提示，不写时说明规则，比如“请输入整数，介于 1 和 5 之间”。
- `prompt`：选中单元格时在旁边显示的提示，读屏也会读出。

空单元格总是符合规则。规则的完整写法见[文档数据 · 数据验证](./data#数据验证)。

## 不符合的单元格

粘贴和填充的值不检查，不符合的单元格会被标记：鼠标悬停时显示原因，选中时在旁边的提示里显示原因，读屏会读出“无效”和原因。

组件实例的 `findInvalid(sheet?)` 列出所有不符合规则的单元格，默认检查所有工作表，可以在提交前检查。

## 在工具栏里设置

- 工具栏的条件格式菜单可以突出显示大于、小于、介于、等于某个值或包含某段文字的单元格，以及重复值、按公式判断、前几项、后几项、高于或低于平均值；也可以加数据条或色阶，或在“管理规则”里编辑、调整顺序、删除规则。
- 工具栏的“数据验证”按钮打开当前单元格所在的规则，没有时为选区新建一条。对话框里的区域可以写几个，用逗号或空格隔开。

## 用代码修改

```ts
sheet.value.transact((tr) => {
  tr.addConditionalFormat({
    range: 'E2:E9',
    when: { op: 'lt', value: 1 },
    style: { tone: 'danger' },
  })
  tr.addValidation({ range: 'D2:D20', when: { op: 'between', value: 1, to: 5 }, integer: true })
})
```

## API

### 事务方法

| 方法                                   | 说明                                             |
| -------------------------------------- | ------------------------------------------------ |
| `addConditionalFormat(rule, sheet?)`   | 在工作表的规则末尾加一条条件格式                 |
| `setConditionalFormats(rules, sheet?)` | 按顺序设置工作表的所有条件格式，`[]` 全部去掉    |
| `clearConditionalFormats(range?)`      | 去掉与区域重叠的条件格式，不传时去掉工作表的所有 |
| `addValidation(rule, sheet?)`          | 在工作表的规则末尾加一条数据验证                 |
| `setValidations(rules, sheet?)`        | 按顺序设置工作表的所有数据验证，`[]` 全部去掉    |
| `clearValidations(range?)`             | 去掉与区域重叠的数据验证，不传时去掉工作表的所有 |

### SheetInvalidCell

`findInvalid` 返回的每一项。

| 属性      | 说明                                     | 类型              |
| --------- | ---------------------------------------- | ----------------- |
| `sheet`   | 工作表的名字                             | `string`          |
| `cell`    | 单元格的位置，如 `'C4'`                  | `string`          |
| `rule`    | 不符合的规则                             | `SheetValidation` |
| `message` | 规则的说明：它的 `message`，或要求填什么 | `string`          |
