# 单元格类型

单元格的 `type` 决定值怎样显示、怎样编辑。内置日期、下拉选项和勾选框三种类型。

## 基础用法

<DocDemo src="sheet/types" column />

| `type`     | 显示                                      | 编辑                                   |
| ---------- | ----------------------------------------- | -------------------------------------- |
| `date`     | 和普通日期一样，按 `format` 显示          | 输入日期，或在单元格下方的日历里点选   |
| `select`   | 选项的值，显示为标签，颜色取选项的 `tone` | 在下方的列表里选，输入文字会筛选列表   |
| `checkbox` | 勾选框，值为 `true` 或 `false`            | 点击勾选框、按空格、双击或按 `F2` 切换 |

选中带列表或日历的单元格时，右侧出现一个展开按钮，也可以按 `Alt` + `↓` 展开。在手机上展开列表或日历时不会弹出键盘。

## 日期

- 除了普通单元格认识的写法，还认 `11/30`、`11-30`、`11月30日`、`2026年11月30日`，没写年份时是今年。
- 在日历里选日期时，原有的时间部分保留。

## 下拉选项

`select` 的选项写在工作簿的 `types` 里：起一个名字，单元格用这个名字作 `type`，和命名样式的用法一样。选项可以是值，也可以是 `{ value, tone }`：

```ts
const book = {
  version: 1,
  types: {
    status: {
      type: 'select',
      options: [
        '未开始',
        { value: '进行中', tone: 'primary' },
        { value: '已完成', tone: 'success' },
      ],
    },
  },
  sheets: [{ name: '任务', cells: [[{ value: '进行中', type: 'status' }]] }],
}
```

- 没有 `tone` 的选项显示为中性色。
- 列表里方向键移动，`Enter` 选定。输入的文字和选项一致时（不区分大小写）记为该选项。

## 勾选框

空格切换选区里所有勾选框：状态相同时一起切换，有勾有不勾时全部勾上。

## 不符合类型的值

读不懂的值照常写入，比如日期单元格里的“明天”、不在选项里的文字。这样的单元格左上角有一个红色小三角，悬停时显示原因，读屏也会读出。

## 自定义类型

要加自己的单元格类型，比如进度条、评分，见[自定义单元格类型](./cell-types)。自定义的类型在[导出图片和打印](./files#导出图片与打印)时画成 `format` 返回的文字，或者用类型的 `draw` 画出。

## API

### 类型设置

写在工作簿的 `types` 里。

| 属性      | 说明              | 类型                                         |
| --------- | ----------------- | -------------------------------------------- |
| `type`    | 类型的名字        | `'date' \| 'select' \| 'checkbox' \| string` |
| `options` | 仅 `select`：选项 | `(SheetValue \| { value, tone? })[]`         |
