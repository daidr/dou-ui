# @dou-ui/nuxt

[DouUI](https://github.com/daidr/dou-ui) 的 Nuxt 模块：组件、指令与常用函数自动导入，样式与配色模式开箱即用，支持服务端渲染。需要 Nuxt 4。

```sh
bun add dou-ui @dou-ui/nuxt
```

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['@dou-ui/nuxt'],
})
```

选项与用法见 [Nuxt 集成](https://github.com/daidr/dou-ui/blob/main/docs/integrations/nuxt.md)。
